# Оновіть свою IDL Codama

Система відвідувачів Codama дозволяє програмно трансформувати та покращувати вашу IDL після створення.

Незалежно від того, чи ви почали з IDL Anchor, чи створили її з нуля, відвідувачі дозволяють вам додатково покращувати та налаштовувати IDL Codama перед створенням клієнтів, наприклад, для оптимізації роботи розробника.

<ArticleSection name="Essential Visitors" id="essential-visitors" level="h2" />

Відвідувачі слідують шаблону відвідувачів, проходячи через вузли вашої IDL та застосовуючи трансформації.

Давайте розглянемо найбільш впливових відвідувачів для створення готових до виробництва SDK:

### Додавання відвідувачів PDA

Щоб додати визначення PDA до ваших програм, ми використовуємо `addPdasVisitor`. Цей відвідувач є важливим, коли ваша IDL Anchor не містить інформації про PDA, але логіка вашої програми спирається на певні адреси, отримані з програми.

Він приймає об'єкт, де ключі - це назви програм, а значення - масиви визначень PDA для додавання.

```ts
codama.update(
    addPdasVisitor({
        // Додайте PDA до програми токенів.
        token: [
            {
                name: 'associatedToken',
                seeds: [
                    variablePdaSeedNode('mint', publicKeyTypeNode()),
                    constantPdaSeedNode(
                        publicKeyTypeNode(),
                        publicKeyValueNode('TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA'),
                    ),
                    variablePdaSeedNode('owner', publicKeyTypeNode()),
                ],
            },
        ],
        // додайте PDA до програми лічильника.
        counter: [
            {
                name: 'counter',
                seeds: [variablePdaSeedNode('authority', publicKeyTypeNode())],
            },
            {
                name: 'counterConfig',
                seeds: [variablePdaSeedNode('counter', publicKeyTypeNode())],
            },
        ],
    }),
);
```

### Відвідувач оновлення облікових записів

Щоб змінити існуючі визначення облікових записів або видалити небажані, ми використовуємо `updateAccountsVisitor`. Цей відвідувач є критично важливим для перейменування облікових записів відповідно до ваших бажаних правил іменування або додавання відсутніх асоціацій КПК.

Ви повинні використовувати це, коли імена облікових записів, згенеровані Anchor, не відповідають налаштуванням іменування вашого клієнта, або коли вам потрібно пов’язати КПК з певними обліковими записами для кращої генерації коду.

```ts
codama.update(
    updateAccountsVisitor({
        vault: {
            // Перейменуйте обліковий запис «сховища» на «безпечний».
            name: 'safe',
            // Перейменуйте обліковий запис «сховища» на «безпечний».
            data: { owner: 'authority' },
            // Створіть новий вузол PDA та прив’яжіть його до цього облікового запису.
            seeds: [variablePdaSeedNode('authority', publicKeyTypeNode())],
        },
        counter: {
            // Видалити обліковий запис «лічильник».
            delete: true,
        },
    }),
);
```

### Відвідувач інструкцій для оновлення

Щоб покращити визначення інструкцій за допомогою кращих значень за замовчуванням, імен або конфігурацій облікових записів, ми використовуємо `updateInstructionsVisitor`. Це один з найпотужніших відвідувачів для покращення взаємодії розробників з вашими згенерованими клієнтами.

Використовуйте його, коли хочете надати розумні значення за замовчуванням для аргументів інструкцій, перейменувати інструкції або облікові записи для ясності або позначити облікові записи як необов'язкові для спрощення використання клієнта.

```ts
codama.update(
    updateDefinedTypesVisitor({
        options: {
            // Перейменуйте тип «опції» на «конфігурації».
            name: 'configs',
            // Перейменуйте поле «sol» на «lamports».
            data: { sol: 'lamports' },
        },
        player: {
            // Видаліть тип «гравець».
            delete: true,
        },
    }),
);
```

### Відвідувач оновлення визначених типів

Щоб змінити власні визначення типів або очистити невикористовувані типи, ми використовуємо `updateDefinedTypesVisitor`. Цей відвідувач допомагає підтримувати чисті, правильно названі типи у ваших згенерованих клієнтах.

Ви повинні використовувати це, коли Anchor генерує імена типів, які не відповідають вашим бажаним домовленостям, або коли вам потрібно видалити застарілі типи з вашої IDL.

```ts
codama.update(
    updateDefinedTypesVisitor({
        options: {
            // Перейменуйте тип «опції» на «конфігурації».
            name: 'configs',
            // Перейменуйте поле «sol» на «lamports».
            data: { sol: 'lamports' },
        },
        player: {
            // Видаліть тип «гравець».
            delete: true,
        },
    }),
);
```

### Відвідувач помилок оновлення

Щоб покращити визначення помилок за допомогою чіткіших назв, повідомлень або кодів, ми використовуємо `updateErrorsVisitor`. Цей відвідувач гарантує, що обробка помилок є описовою та відповідає послідовним шаблонам.

Використовуйте його, коли вам потрібні більш описові назви або повідомлення про помилки, ніж ті, що генерує Anchor, або коли вам потрібно стандартизувати коди помилок у вашому програмному комплексі.

```ts
codama.update(
    updateErrorsVisitor({
        invalidPda: {
            // Перейменуйте помилку «invalidPda» на «invalidProgramDerivedAddress».
            name: 'invalidProgramDerivedAddress',
            // Змініть повідомлення про помилку.
            message: 'The program-derived address is invalid.',
            // Змініть код помилки.
            code: 123,
        },
        accountMismatch: {
            // Видаліть помилку «Невідповідність облікового запису».
            delete: true,
        },
    }),
);
```

### Відвідувач програм оновлення

Для зміни інформації на рівні програми, такої як назви, версії або відкриті ключі, ми використовуємо `updateProgramsVisitor`. Цей відвідувач необхідний для підтримки точних метаданих програми.

Використовуйте його, коли вам потрібно оновити версії програм, стандартизувати назви програм у різних середовищах або видалити застарілі програми з вашої IDL.

```ts
codama.update(
    updateProgramsVisitor({
        splToken: {
            // Перейменуйте програму «splToken» на «token».
            name: 'token',
            // Змініть версію програми.
            version: '3.0.0',
            // Змініть відкритий ключ програми.
            publicKey: 'TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA',
        },
        splAssociatedToken: {
            // Видаліть програму «splAssociatedToken».
            delete: true,
        },
    }),
);
```
