# 결론

축하합니다! 이제 `Codama로 SDK 만들기` 과정을 완료하셨습니다. Codama IDL이 핵심 개념부터 실제 구현 세부 사항에 이르기까지 어떻게 작동하는지에 대한 견고한 이해를 갖추게 되었습니다.

## 학습 내용

이 과정을 통해 다음을 포함한 필수 지식을 습득했습니다:
- Codama는 무엇이며 `nodes`, `visitors`, `renderers`가 어떻게 사용되는지
- 맨 처음부터 Codama IDL을 구축하는 방법
- Anchor IDL에서 Codama IDL을 구축하고 필요에 따라 업데이트하는 방법
