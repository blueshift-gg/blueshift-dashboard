# Висновок

Вітаємо! Ви завершили курс «Створіть свій SDK за допомогою Codama». Тепер у вас є міцна основа розуміння того, як працює Codama IDL, від основних концепцій до практичних деталей впровадження.

## Чого ви навчилися

Протягом цього курсу ви отримали необхідні знання про:
- Що таке Codama та як використовуються «вузли», «відвідувачі» та «рендерери»
- Як створити Codama IDL з нуля
- Як створити Codama IDL з Anchor IDL та оновити його за потреби

## Наступні кроки

Тепер ви готові розпочати створення свого першого SDK за допомогою Codama! Найкращий спосіб закріпити свої знання – це практична практика. Ми рекомендуємо вам:

1. Перейти до розділу [Виклики](/uk/challenges)
2. Створити SDK для однієї з програм
3. Використати SDK для створення тестів для вашої програми
4. Приєднатися до нашої спільноти, щоб поділитися своїм прогресом та отримати допомогу
