# Codama

Codama — це найшвидший спосіб створювати типобезпечні клієнти для програм Solana на різних мовах та фреймворках, створювати інструменти CLI та надавати дослідникам багату інформацію про програму.

Все починається з Codama IDL — стандартизованого формату, який описує будь-яку програму Solana та служить основою для створення всіх інструментів, пов'язаних з програмою.

З одного Codama IDL ви можете створювати:
- Типобезпечні клієнти для JavaScript, Rust, Python тощо
- Інструменти CLI для взаємодії з вашою програмою
- Документацію, яка синхронізується з вашим кодом
- Інтеграції Explorer, які розуміють структуру вашої програми
- Утиліти тестування, які знають інтерфейс вашої програми

Codama позбавляє вас від нудної роботи з підтримки клієнтів на різних мовах та фреймворках.

Замість того, щоб вручну писати та оновлювати клієнтський код щоразу, коли ваша програма змінюється, ви описуєте свою програму один раз у форматі Codama IDL, застосовуєте всі необхідні перетворення за допомогою відвідувачів та генеруєте все інше автоматично.

<ArticleSection name="Основні концепції" id="core-concept" level="h2" />
Архітектура Codama обертається навколо трьох фундаментальних концепцій: вузлів, відвідувачів та рендерерів.

### Вузли

Все в Codama представлено як дерево вузлів. Вузол – це структурований об'єкт даних, який описує один конкретний аспект вашої програми Solana.

Вся ваша програма стає ієрархічним деревом, починаючи з `RootNode` на вершині.

Існують різні типи вузлів:
- **Структурні вузли** (`RootNode`, `ProgramNode`, `AccountNode`, `InstructionNode`, ...): Визначають скелет вашої програми
- **Типові вузли** (`NumberTypeNode`, `StringTypeNode`, `StructTypeNode`, `ArrayTypeNode`): Описують структури даних та типи полів
- **Вузли значень** (`NumberValueNode`, `StringValueNode`): Представляють значення за замовчуванням та константи

> Кожен тип вузла виконує певну функцію та забезпечує узгоджений інтерфейс для представлення своїх даних. Відвідувачі, що орієнтовані на певну мову, можуть потім переміщатися по цих вузлах та перетворювати їх на відповідні представлення для різних цільових мов, що дозволяє створювати складні описи програм шляхом комбінування простих вузлів.
### Відвідувачі

Відвідувачі – це функції, які перетинають ваше дерево вузлів, щоб проаналізувати або перетворити його.

Вони реалізують шаблон відвідувачів, "відвідуючи" кожен вузол у вашому дереві та виконуючи над ним операції.

Існує 2 типи відвідувачів:

Два типи відвідувачів:
- Відвідувачі аналізу (лише для читання): Перетинають вузли та повертають інформацію за допомогою `codama.accept()`
- Відвідувачі трансформації: Перетинають вузли та повертають змінене дерево за допомогою `codama.update()`

> Відвідувачі розділяють те, чим є ваша програма (вузли), від того, що ви хочете з нею робити (операції). Це означає, що ви можете застосовувати ті самі перетворення до будь-якої Codama IDL, незалежно від того, як вона була створена.

### Рендерери

Рендерери – це функції відвідувачів, які перетворюють вашу Codama IDL на клієнтський код для певних мов програмування.

Кожен рендерер перетинає вузли IDL та генерує відповідні файли коду, типи та інтерфейси для своєї цільової мови.

Щоб використовувати рендерер, вкажіть базовий каталог, де слід зберігати згенеровані файли, а також додаткову конфігурацію для налаштування виводу:

```ts
import { createFromRoot, programNode, rootNode } from 'codama';
import { renderJavaScriptVisitor, renderRustVisitor } from '@codama/renderers';

// створи або підгрузи Codama IDL.
const codama = createFromRoot(rootNode(programNode({ ... })));

// Рендер SDKs з твого IDL.
codama.accept(renderJavaScriptVisitor('clients/js/src/generated', { ... }));
codama.accept(renderRustVisitor('clients/rust/src/generated', { ... }));
```

> На даний момент доступні лише такі рендерери: `renderJavaScriptVisitor` (сумісний з `@solana/kit`), `renderJavaScriptUmiVisitor` (сумісний з `@metaplex-foundation/umi` та `@solana/web3.js`) та `renderRustVisitor`.

<ArticleSection name="Встановлення" id="installation" level="h2" />

Встановіть основний пакет Codama, використовуючи ваш бажаний менеджер пакетів:

```
pnpm install codama
```
Це включає пакети `@codama/visitors` та `@codama/nodes`, які надають усе необхідне для створення та маніпулювання IDL.

> Окремі пакети, такі як `@codama/visitors` та `@codama/nodes`, можна встановити окремо, якщо ви віддаєте перевагу детальному контролю над залежностями.

Для генерації клієнтського коду вам також знадобиться пакет renderers:

```
pnpm install codama @codama/renderers
```
Пакет renderers розповсюджується окремо, оскільки він вимагає доступу до файлової системи та працює лише в середовищах Node.js, тоді як основна бібліотека Codama працює всюди (Node.js, браузери тощо).

<ArticleSection name="Підготовка" id="set-up" level="h2" />

Codama надає інтерфейс командного рядка (CLI), який спрощує роботу з IDL та генерацію клієнтського коду. CLI обробляє керування конфігурацією та виконання скриптів, що спрощує налаштування автоматизованих робочих процесів.

Встановіть пакет CLI та ініціалізуйте свій проект:


```
pnpm install @codama/cli
pnpm codama init
```
Команда init запитає у вас:
- Шлях до вашого IDL-файлу (підтримує IDL Codama та Anchor)
- Пресети скриптів, які ви хочете використовувати (JavaScript, Rust тощо)

Це створює файл конфігурації, який визначає ваш вихідний код IDL та сценарії генерації, і виглядає так:

```json
{
    "idl": "path/to/your/idl",
    "before": [
        "./custom-transforms.js",
        { "from": "@codama/visitors#removeTypes", "args": [["internal"]] }
    ],
    "scripts": {
        "js": [
            { "from": "@codama/renderers-js", "args": ["clients/js/src"] }
        ],
        "rust": [
            { "from": "@codama/renderers-rust", "args": ["clients/rust/src"] }
        ]
    }
}
```

> `before` містить `Visitors`, які запускаються перед кожним скриптом (для перетворень, очищення тощо), а `scripts` містить `Renderers`, що використовуються для генерації клієнтів.

Ви можете виконати налаштовані скрипти за допомогою команди `run`:

```
pnpm codama run # Запустити лише кроки підготовки
pnpm codama run js rust # Запустити генератори певних мов
pnpm codama run --all # Запустити всі налаштовані скрипти
```

### Без CLI

Якщо ви не хочете використовувати CLI, ви можете створити файл `codama.ts` у своєму репозиторії, вказати логіку Codama IDL (імпорт, відвідувачі та рендерери), а потім виконати:

```
pnpx tsx codama.ts
```
