# Створимо свій IDL Codama з IDL Anchor

Створення IDL Codama з Anchor надзвичайно просте. Після створення вашого IDL Anchor за допомогою збірки anchor нам потрібно встановити пакет '@codama/nodes-from-anchor':

```
pnpm install codama @codama/nodes-from-anchor
```

А потім конвертуйте IDL-тег Anchor безпосередньо за допомогою функції `rootNodeFromAnchor`:

```ts
import { createFromRoot } from 'codama';
import { rootNodeFromAnchor } from '@codama/nodes-from-anchor';
import anchorIdl from 'anchor-idl.json';

const codama = createFromRoot(rootNodeFromAnchor(anchorIdl));
```

Це надає вам повністю функціональну IDL Codama, готову до створення клієнта. Однак справжня сила Codama полягає в її здатності покращувати та налаштовувати ваш IDL понад можливості, які дозволяє створювати необроблені визначення Anchor.

Оскільки процес конвертації зосереджений на структурному перетворенні, вам часто знадобиться додати зручні для розробників функції, такі як користувацькі правила іменування, додаткова інформація про тип або спеціалізовані методи клієнта. Система відвідувачів Codama робить ці покращення простими та потужними.

Ви можете дізнатися більше про те, як налаштувати та покращити конвертований IDL за допомогою відвідувачів, у уроці [Оновлення IDL Codama](/en/courses/create-your-sdk-with-codama/updating-codama-idl).
