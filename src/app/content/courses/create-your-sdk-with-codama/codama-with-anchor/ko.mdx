# Anchor IDL에서 Codama IDL 구축하기

Anchor에서 Codama IDL을 생성하는 것은 매우 간단합니다. anchor build를 사용하여 Anchor IDL을 생성한 후, '@codama/nodes-from-anchor' 패키지를 설치해야 합니다:

```
pnpm install codama @codama/nodes-from-anchor
```

그 다음, `rootNodeFromAnchor` 함수를 사용하여 Anchor IDL을 직접 변환합니다:

```ts
import { createFromRoot } from 'codama';
import { rootNodeFromAnchor } from '@codama/nodes-from-anchor';
import anchorIdl from 'anchor-idl.json';

const codama = createFromRoot(rootNodeFromAnchor(anchorIdl));
```

이렇게 하면 클라이언트 생성을 위한 완전히 기능하는 Codama IDL을 얻게 됩니다. 그러나 Codama의 진정한 강점은 원시 Anchor 정의로는 불가능한 방식으로 IDL을 향상시키고 사용자 정의할 수 있는 능력에서 나옵니다.

변환 프로세스는 구조적 번역에 중점을 두므로, 종종 사용자 정의 명명 규칙, 추가 유형 정보 또는 특수 클라이언트 메서드와 같은 개발자 친화적인 기능을 추가하고자 할 것입니다. Codama의 visitor 시스템은 이러한 개선 작업을 간단하고 강력하게 만듭니다.

visitor를 사용하여 변환된 IDL을 사용자 정의하고 향상시키는 방법에 대한 자세한 내용은 [Codama IDL 업데이트](/en/courses/create-your-sdk-with-codama/updating-codama-idl) 레슨에서 확인할 수 있습니다.
