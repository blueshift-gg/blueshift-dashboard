# 툴링

sBPF Assembly 프로그램을 작성하고 빌드하는 것은 전통적으로 전체 Solana toolchain을 필요로 했으며, 이는 설정이 복잡하고 플랫폼에 따라 달라질 수 있습니다. 바로 이러한 이유로, [Dean](https://x.com/deanmlittle)은 [Claire](https://x.com/clairefxyz)의 기여와 함께 sBPF: sBPF Assembly 프로그램을 생성하고 빌드하기 위한 완벽한 toolkit을 만들었습니다.

<ArticleSection name="Installation" id="installation" level="h2" />

다음 명령을 사용하여 package를 설치하는 것부터 시작하겠습니다:

```
cargo install --git https://github.com/blueshift-gg/sbpf.git
```

그 후 다음의 모든 command를 사용할 수 있습니다:
- `init`: 새 project scaffold를 생성합니다.
- `build`: Solana program executable로 컴파일합니다.
- `deploy`: program을 빌드하고 deploy합니다.
- `test`: deploy된 program을 test합니다.
- `e2e`: program을 빌드하고, deploy하며, test합니다.
- `clean`: 빌드 및 deploy artifact를 정리합니다.
- `help`: 이 메시지 또는 지정된 subcommand의 도움말을 출력합니다.

```text
Usage: sbpf <COMMAND>

Commands:
  init    Create a new project scaffold
  build   Compile into a Solana program executable
  deploy  Build and deploy the program
  test    Test deployed program
  e2e     Build, deploy and test a program
  clean   Clean up build and deploy artifacts
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
```

<ArticleSection name="Initialize a new project" id="initialize-a-new-project" level="h2" />

새 project를 생성하려면 `sbpf init` command를 사용하십시오. 기본적으로 Mollusk를 사용하여 Rust test가 포함된 project를 초기화합니다. `--ts-tests` option을 사용하여 TypeScript test가 포함된 project를 초기화할 수도 있습니다.

```text
sbpf init --help
Create a new project scaffold

Usage: sbpf init [OPTIONS] [NAME]

Arguments:
  [NAME]  The name of the project to create

Options:
  -t, --ts-tests  Initialize with TypeScript tests instead of Mollusk Rust tests
  -h, --help      Print help information
  -V, --version   Print version information
```

project를 초기화한 후, project directory로 이동하여 다른 command를 사용하여 program을 빌드하고, deploy하며, test할 수 있습니다.

<ArticleSection name="Building Programs" id="building-programs" level="h2" />

sBPF는 사용자의 setup과 필요에 따라 두 가지 빌드 option을 제공합니다:

### sBPF Build

이 빌드 command는 추가 dependencies가 필요 없는 독립형 assembler를 사용합니다. 이는 어떤 platform에서든 "그냥 작동"하기 때문에 학습 및 실험에 적합합니다.

```
sbpf build
```

### 고급 사용법

program과 동일한 이름으로 src directory에 포함함으로써 기본 linker를 사용자 지정 linker 파일로 재정의할 수 있습니다. 예를 들어:

```text
src/example/example.s
src/example/example.ld
```

<ArticleSection name="Development Environment" id="development-environment" level="h2" />

최고의 개발 경험을 위해, [VS Code sBPF Assembly extension](https://github.com/deanmlittle/vscode-sbpf-asm)을 설치하는 것을 고려하십시오. 이 extension은 다음을 제공합니다:
- sBPF assembly를 위한 Syntax highlighting
- instruction 및 register를 위한 Code completion
- Error detection 및 warnings
