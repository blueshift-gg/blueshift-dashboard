# Інструменти

Написання та побудова програм sBPF Assembly традиційно вимагало повного набору інструментів Solana, який може бути складним для налаштування та залежним від платформи. Саме з цієї причини [Dean](https://x.com/deanmlittle) за участю [Claire](https://x.com/clairefxyz) створив sBPF: повний набір інструментів для створення та побудови програм sBPF Assembly.

<ArticleSection name="Встановлення" id="installation" level="h2" />

Почнемо з встановлення пакета, виконавши такі дії:

```
cargo install --git https://github.com/blueshift-gg/sbpf.git
```

Після цього ми зможемо виконувати всі наступні команди:
- `init`: Створити новий каркас проекту.
- `build`: Компілювати у виконуваний файл програми Solana.
- `deploy`: Зібрати та розгорнути програму.
- `test`: Тестувати розгорнуту програму.
- `e2e`: Зібрати, розгорнути та протестувати програму.
- `clean`: Очистити артефакти збірки та розгортання.
- `help`: Вивести це повідомлення або довідку до заданої(их) підкоманди(ок).

```text
Usage: sbpf <COMMAND>

Commands:
  init    Create a new project scaffold
  build   Compile into a Solana program executable
  deploy  Build and deploy the program
  test    Test deployed program
  e2e     Build, deploy and test a program
  clean   Clean up build and deploy artifacts
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
```

<ArticleSection name="Ініціалізація нового проєкту" id="initialize-a-new-project" level="h2" />

Щоб створити новий проект, скористайтеся командою `sbpf init`. За замовчуванням вона ініціалізує проект тестами Rust, використовуючи Mollusk. Ви також можете ініціалізувати проект тестами TypeScript, використовуючи опцію `--ts-tests`.

```text
sbpf init --help
Create a new project scaffold

Usage: sbpf init [OPTIONS] [NAME]

Arguments:
  [NAME]  The name of the project to create

Options:
  -t, --ts-tests  Initialize with TypeScript tests instead of Mollusk Rust tests
  -h, --help      Print help information
  -V, --version   Print version information
```

Після ініціалізації проєкту ви можете перейти до каталогу проєкту та використовувати інші команди для збирання, розгортання та тестування вашої програми.

<ArticleSection name="Збірка Програм" id="building-programs" level="h2" />

sBPF пропонує два варіанти збірки залежно від ваших налаштувань та потреб:

### Збірка sBPF

Команда збірки використовує окремий асемблер, який не потребує додаткових залежностей. Він ідеально підходить для навчання та експериментів, оскільки «просто працює» на будь-якій платформі.

```
sbpf build
```

### Розширене використання

Ви можете перезаписати стандартний лінкер за допомогою власного файлу лінкера, включивши його до каталогу src з тим самим ім'ям, що й ваша програма. Наприклад:

```text
src/example/example.s
src/example/example.ld
```
