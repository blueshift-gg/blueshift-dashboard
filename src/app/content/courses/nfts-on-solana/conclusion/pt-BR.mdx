# Principais Aprendizados

Você entende por que mintar um NFT na Ethereum custa $50-100 enquanto na Solana custa $0,02. Por que NFTs comprimidos custam $0,0001. A economia permite aplicações diferentes: jogos com milhões de itens, programas de fidelidade com milhões de membros, coleções em escalas impossíveis em redes caras.

Você conhece três padrões de NFT: Token Metadata (original, compatibilidade máxima), Core (mais novo, mais barato, mais simples) e NFTs Comprimidos (escala massiva, dramaticamente mais baratos). Cada um tem casos de uso. A escolha depende dos seus requisitos.

Este conhecimento o prepara para construir: entender os padrões permite a implementação.

<ArticleSection name="O que Você Aprendeu" id="what-you-learned" level="h2" />

**Por que a Solana para NFTs:**

A diferença de custo é 1.000-500.000x mais barata dependendo da abordagem. Isso não é marginal — desbloqueia aplicações inteiramente novas.

A velocidade permite mint em tempo real. Ingressos de eventos, itens em jogo, recompensas instantâneas todos se tornam práticos com confirmação sub-segundo.

NFTs comprimidos armazenam milhões de NFTs em uma única conta. 1 milhão de NFTs por $600 no total vs $50-150 milhões na Ethereum.

**Metaplex Token Metadata:**

Padrão original. Duas contas por NFT: mint SPL Token + PDA de metadados. JSON off-chain para dados detalhados. Coleções com verificação. Royalties com aplicação pelo marketplace.

Suporte máximo do ecossistema. Todas as principais carteiras, marketplaces e ferramentas. Testado em produção por anos. Custo: ~$0,03 por NFT.

**Metaplex Core:**

Padrão mais novo. Conta única por NFT. Sem dependência do SPL Token. Arquitetura mais simples, menores custos.

Adoção crescente. Projetos modernos escolhendo Core. 50% mais barato que Token Metadata. Custo: ~$0,0075 por NFT.

**NFTs Comprimidos:**

Arquitetura de árvore Merkle. Milhões de NFTs em uma conta de árvore. Provas verificam propriedade sem contas dedicadas.

Requer indexadores (trade-off de centralização). Permite escala massiva. 100x mais barato que NFTs regulares. Custo: ~$0,0006 por NFT para coleções de milhão+.

<ArticleSection name="A Matriz de Decisão dos Padrões" id="decision-matrix" level="h2" />

Escolha Token Metadata quando:
- Compatibilidade máxima necessária
- Projeto existente já o utilizando
- NFTs programáveis necessários (pNFTs)
- Leituras puramente on-chain sem indexadores

Escolha Core quando:
- Novo projeto começando do zero
- Quer arquitetura moderna e limpa
- Otimização de custo é importante (50% mais barato)
- Pode verificar suporte de marketplace

Escolha NFTs Comprimidos quando:
- Escala é prioridade (100K+ NFTs)
- Custo é crítico (100x mais barato)
- Pode depender de indexadores
- Casos de uso: jogos, fidelidade, grandes coleções

**Não há escolha errada:**

Todos os três padrões estão prontos para produção. Token Metadata impulsiona a maioria das coleções existentes. Core impulsiona projetos modernos. NFTs Comprimidos impulsionam aplicações em escala.

Escolha baseado nos requisitos, não em tendências.

<ArticleSection name="Coleções e Marketplaces" id="collections-marketplaces" level="h2" />

**Coleções:**

Agrupam NFTs relacionados. Fornecem verificação contra falsificações. Permitem rastreamento de preço de piso. Necessárias para listagem em marketplace.

O NFT da coleção (supply=1) é o identificador da coleção. NFTs individuais referenciam a coleção. A autoridade da coleção verifica a associação. Associação não verificada é sinalizada como suspeita.

**Royalties:**

Embutidos nos metadados. Vendas secundárias dividem o pagamento: vendedor recebe a maior parte, criadores recebem porcentagem.

Não aplicados pelo protocolo (exceto pNFTs). Marketplaces honram voluntariamente. A maioria dos grandes marketplaces respeita os royalties.

**Integração com marketplaces:**

Token Metadata: Suporte universal (Magic Eden, Tensor, OpenSea).

Core: Suporte crescente, verifique antes de lançar.

NFTs Comprimidos: Suporte especializado de marketplace (Tensor, Hyperspace).

Verifique se seu marketplace alvo suporta o padrão escolhido antes de mintar a coleção.

<ArticleSection name="Análise de Custos" id="cost-analysis" level="h2" />

**Coleção de 10.000 NFTs:**

| Padrão | Custo | Por NFT |
|----------|------|---------|
| Ethereum ERC-721 | $500.000-1.500.000 | $50-150 |
| Token Metadata | $300 | $0,03 |
| Core | $75 | $0,0075 |
| Comprimido | $55 | $0,0055 |

**Coleção de 1.000.000 de NFTs:**

| Padrão | Custo | Por NFT |
|----------|------|---------|
| Ethereum ERC-721 | $50-150 milhões | $50-150 |
| Token Metadata | $29.000 | $0,029 |
| Core | $7.000 | $0,007 |
| Comprimido | $600 | $0,0006 |

A lacuna de escala é intransponível. Aplicações viáveis na Solana são impossíveis na Ethereum. Não "ligeiramente mais barato" — ordens de magnitude mais barato.

<ArticleSection name="Caminhos de Implementação" id="implementation-paths" level="h2" />

Entender os padrões permite construir. Três abordagens de implementação:

**SDKs JavaScript/TypeScript:**

O Metaplex Umi fornece SDK TypeScript para todos os três padrões. Mint, transfira, atualize NFTs a partir de código client-side ou server-side.

```typescript
import { createNft } from '@metaplex-foundation/mpl-token-metadata'
```

Bom para: Ferramentas, marketplaces, plataformas de mint, carteiras.

**Programas Solana (Rust/Anchor):**

Construa programas on-chain que interagem com NFTs. Lógica personalizada, integração de protocolo, composabilidade DeFi.

```rust
use mpl_token_metadata::instructions::CreateV1;
```

Bom para: Jogos, protocolos DeFi, DAOs, mecânicas NFT personalizadas.

**Ferramentas sem código:**

Metaplex Candy Machine, Sugar CLI e outras ferramentas gerenciam os detalhes técnicos. Configure a coleção, faça upload dos metadados, deploy.

Bom para: Artistas, pequenos projetos, lançamentos rápidos sem programação.

<ArticleSection name="O Ecossistema NFT da Solana" id="solana-ecosystem" level="h2" />

Metaplex Discord, Solana Discord canal #nfts, comunidades de projetos individuais. Desenvolvimento ativo, iteração rápida.

<ArticleSection name="Principais Aprendizados" id="key-takeaways" level="h2" />

**Custo permite escala:**

$0,0001 por mint (comprimido) vs $50+ (Ethereum) desbloqueia aplicações impossíveis em outros lugares. Jogos, fidelidade, adoção em massa todos se beneficiam.

**Três padrões atendem necessidades diferentes:**

Token Metadata para compatibilidade. Core para eficiência moderna. Comprimidos para escala massiva. Todos prontos para produção. Escolha baseado nos requisitos.

**A infraestrutura é madura:**

Metaplex fornece padrões. Marketplaces fornecem liquidez. Carteiras fornecem UX. Indexadores fornecem acesso a dados. A stack completa existe.

**A Solana é infraestrutura de NFTs:**

Não apenas "NFTs mais baratos da Ethereum." Arquitetura diferente permitindo escala diferente. NFTs comprimidos são exclusivamente Solana. Token Extensions adicionam recursos impossíveis em outros lugares.

Você entende os padrões de NFT da Solana. Por que existem. Quando usar cada um. Quais trade-offs envolvem. Hora de construir seu projeto NFT com esse conhecimento.
