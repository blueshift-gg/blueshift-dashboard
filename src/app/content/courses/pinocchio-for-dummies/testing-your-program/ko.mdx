# 프로그램 테스트하기

메인넷 배포 전에 철저한 테스트는 잠재적인 버그와 취약점을 식별하기 위해 필수적입니다.

잘 테스트된 프로그램은 재정적 손실을 방지하고, 사용자 신뢰를 구축하며, 다양한 조건에서 애플리케이션이 올바르게 작동하도록 보장합니다.

<ArticleSection name="Mollusk Tests" id="mollusk-tests" level="h2" />

복잡한 프로그램 상태를 설정하거나 복잡한 온체인 상호작용이 필요한 경우 어려움을 겪을 때, Mollusk는 테스트 환경에 대해 더 세부적인 제어를 제공합니다.

Mollusk는 Rust 테스트 프레임워크로, 솔라나 프로그램에 맞게 특별히 설계되었으며 다음과 같은 기능을 제공합니다:
- 네트워크 오버헤드 없이 격리된 환경에서 프로그램 로직을 테스트합니다
- 복잡한 계정 상태와 프로그램 조건을 쉽게 설정합니다
- 전체 통합 테스트보다 테스트를 더 빠르게 실행합니다
- 특정 블록체인 조건 및 엣지 케이스를 모의합니다

Mollusk 테스트에 대해서는 [여기](/en/courses/testing-with-mollusk)에서 자세히 다루었습니다.

pinocchio 프로그램을 테스트하려면, `lib.rs` 파일에 `test` 설정 플래그와 함께 `test.rs` 파일을 임포트하면 됩니다:

```rust
#[cfg(test)]
pub mod tests;
```

다음 명령어를 사용하여 테스트를 실행하세요:

```
cargo test-sbf
```
