# 결론

축하합니다! 'Testing with Surfpool' 과정을 완료하셨습니다. 이제 Surfpool 사용법을 완벽하게 이해하셨을 것입니다. Surfpool은 메인넷(mainnet) 상태를 로컬 개발 환경으로 직접 가져와 원활한 Cross-Program Invocation (CPI) 테스트를 가능하게 하는 강력한 테스트 프레임워크입니다.

<ArticleSection name="What you've learned" id="what-you-learned" level="h2" />

이 과정을 통해 다음과 같은 Surfpool의 핵심 개념들을 익히셨습니다:
- **메인넷 시뮬레이션(Mainnet simulation)**: Surfpool이 메인넷(mainnet) account를 필요할 때(just-in-time) 어떻게 가져와 CPI 테스트를 위한 복잡한 설정을 제거하는지
- **고급 제어(Advanced control)**: 모든 epoch/slot/timestamp로 시간 여행(time travel)을 하고, 블록 생산을 일시 중지하며, 시스템 변수를 조작하는 방법
- **account 수정(Account modification)**: SOL 공급(supply) 매개변수를 설정하고, 프로그램(program) 간에 account를 전송하며, token account 데이터를 업데이트하는 방법
