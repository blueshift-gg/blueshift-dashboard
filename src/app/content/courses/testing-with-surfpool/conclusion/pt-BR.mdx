# Conclusão

Parabéns! Você concluiu o curso de Testes com Surfpool. Agora você tem uma compreensão abrangente de como usar o Surfpool, um framework de testes poderoso que traz o estado da mainnet diretamente para o seu ambiente de desenvolvimento local, para testes contínuos de Cross-Program Invocation.

<ArticleSection name="O que você aprendeu" id="what-you-learned" level="h2" />

Ao longo deste curso, você dominou conceitos essenciais do Surfpool:
- **Simulação da mainnet**: Como o Surfpool busca contas da mainnet just-in-time, eliminando a configuração complexa para testes de CPI
- **Controle avançado**: Viajar no tempo para qualquer epoch/slot/timestamp, pausar a produção de blocos e manipular variáveis do sistema
- **Modificação de contas**: Definir parâmetros de oferta de SOL, transferir contas entre programas e atualizar dados de contas de token
