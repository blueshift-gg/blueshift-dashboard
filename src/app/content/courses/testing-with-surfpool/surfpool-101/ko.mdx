# Surfpool 101

![Testing with Surfpool](/graphics/course-banners/testing-with-surfpool.png)

Cross-Program Invocations (CPI)에 의존하는 Solana 프로그램을 테스트하려면 전통적으로 개발자가 mainnet에서 accounts와 programs를 덤프한 다음 로컬 validator에 업로드해야 합니다.

이 과정은 소수의 accounts에는 작동하지만, Jupiter와 같이 40개 이상의 accounts와 8개 이상의 programs에 의존할 수 있는 복잡한 programs에 CPI를 테스트할 때는 완전히 비현실적이 됩니다.

Surfpool은 개발자가 요청 시 가져온 mainnet accounts를 사용하여 프로그램을 로컬에서 시뮬레이션할 수 있도록 함으로써 이 문제를 해결하며, 추가적인 기능들도 제공합니다:
- **시스템 변수 사용자 정의**: 시간 여행 (어떤 과거 slot이나 timestamp에서든 프로그램을 테스트), 시계 일시 중지, 또는 블록 생성 중단
- **account 데이터 수정**: SOL 공급량 설정 (총 공급량, 유통 공급량, 비유통 공급량), programs 간 account 데이터 전송, 또는 account 핵심 데이터 및 token account 정보 업데이트
- **체인 데이터 분석**: compute units, account 변경 사항, 실행 세부 정보를 위해 transactions을 프로파일링하고, signature, UUID, 또는 tag별로 상세 프로필을 검색

<ArticleSection name="What is Surfpool" id="what-is-surfpool" level="h2" />

[Surfpool](https://docs.surfpool.run/)은 포괄적인 SDK이자 툴링 스위트이며, **Surfnet**은 Surfpool이 생성하는 로컬 Solana 네트워크입니다. Surfpool을 개발 환경으로, Surfnet을 그 안에서 실행되는 블록체인 네트워크로 생각하세요.

Surfnet은 solana-test-validator를 대체하는 드롭인 솔루션 역할을 하며, Solana 개발자를 위한 최고의 개발 경험을 제공하기 위해 특별히 제작되었습니다.

[TxTx](https://x.com/txtx_sol) 팀이 개발한 Surfpool은 Infrastructure as Code를 Anchor 기반 프로젝트에 원활하게 통합하여, 모든 Solana 네트워크(프라이빗 또는 퍼블릭)에 재현 가능하고, 감사 가능하며, 안전한 배포를 가능하게 합니다.

<ArticleSection name="First Steps" id="first-steps" level="h2" />

Surfnet을 실행하는 데 필요한 모든 것은 Surfpool SDK에 포함되어 있습니다. 설치는 운영 체제에 따라 다르므로, 귀하의 특정 설정에 대한 공식 [설치 페이지](https://docs.surfpool.run/install)를 따르십시오.

Surfpool SDK를 설치한 후, 다음 명령어로 Surfnet을 시작합니다:

```bash
surfpool start
```

이 명령어는 표준 로컬 validator 포트 (`http://127.0.0.1:8899`)에서 Surfnet을 시작하고 다음을 표시하는 터미널 UI를 제공합니다:
- **Slots 및 Epoch**: 현재 실행 중인 slots은 400ms마다 자동으로 처리됩니다. 다음 slot으로 수동으로 진행하려면 **Tab**을 사용하고, 자동 블록 생성을 일시 중지/재개하려면 **Spacebar**를 사용하세요.
- **Transaction 로그**: transactions이 실행하는 모든 것을 보여주는 타임스탬프가 찍힌 활동 스트림

브라우저 기반 경험을 위해, [이 링크](http://127.0.0.1:8899)에서 Surfpool Studio에 연결하세요.

> Surfpool Studio에는 모든 터미널 UI 기능이 포함되어 있으며, 시간 여행 및 모든 mint에 대해 모든 account에 tokens을 추가하는 것과 같은 추가 기능도 제공합니다.

### 프로그램 배포

Surfnet 설정이 완료되면, 프로그램을 배포하고 개발을 시작하세요.

**Anchor 프로그램**: `[programs.localnet]`에 맞게 구성된 `Anchor.toml`과 함께 `anchor deploy`를 사용하세요.

**Pinocchio 프로그램**: config가 localnet으로 설정된 Solana CLI를 통해 배포하세요: `solana program deploy ./target/deploy/your_program.so --program-id ./target/deploy/your_program-keypair.json`

> Anchor Workspace에서 `surfpool start`를 실행하면 Infrastructure as Code를 사용하도록 안내하여 Surfnet에 프로그램을 원활하게 자동 배포할 수 있습니다.

### 프로그램 테스트

localnet에 배포한 후, 로컬 validator를 대상으로 Surfnet에 연결하세요:

```ts
import { Connection } from "@solana/web3.js";

const connection = new Connection("http://localhost:8899", "confirmed");
```
