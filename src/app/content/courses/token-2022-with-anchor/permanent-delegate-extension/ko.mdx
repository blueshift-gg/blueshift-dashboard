# Permanent Delegate 확장

`PermanentDelegate` extension은 Mint account 확장으로, 해당 Mint의 모든 토큰에 대해 영구적인 delegate를 허용하며, 이 delegate는 모든 token account에서 해당 Mint의 토큰을 전송하거나 소각할 수 있습니다.

<ArticleSection name="Initializing the Mint Account" id="initializing-the-mint-account" level="h2" />

Mint account에 `PermanentDelegate` extension을 초기화하려면, `Anchor`가 제공하는 매크로를 사용하면 됩니다.

Permanent Delegate extension을 사용하여 Mint를 생성하는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateMint<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    #[account(
        init,
        payer = signer,
        mint::decimals = 6,
        mint::authority = signer.key(),
        mint::token_program = token_program
        extensions::permanent_delegate::delegate = signer,
    )]
    pub mint: InterfaceAccount<'info, Mint>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

<ArticleSection name="Permissioned Actions" id="permissioned-actions" level="h2" />

취소 가능한 일반 delegate와 달리, 이 delegate authority는 영구적이며 불변합니다.

이는 `transfer()`, `burn()`, `approve()`, `freeze()`와 같은 모든 일반적인 작업을 실제 소유자의 signature 없이 authority가 필요할 때마다 직접 실행할 수 있음을 의미합니다.

이는 우리가 일반적인 `transferChecked()`, `burnChecked()`, ... instructions를 사용하고, PermanentDelegate authority를 `authority` 필드에 전달하기만 하면 된다는 것을 의미합니다.
