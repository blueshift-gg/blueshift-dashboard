# Memo Transfer 익스텐션

MemoTransfer 익스텐션은 Token account 익스텐션으로, token account로 들어오는 모든 transfer에 memo가 포함되도록 강제하여 거래 추적 및 사용자 식별을 향상시키는 데 기여합니다.

<ArticleSection name="Initializing the Token Account" id="initializing-the-token-account" level="h2" />

Anchor에는 memo_transfer 익스텐션에 대한 매크로가 없으므로, raw CPI를 사용하여 Token account를 생성할 것입니다.

Memo Transfer 익스텐션을 사용하여 token을 생성하는 방법은 다음과 같습니다:

```rust
use anchor_lang::prelude::*;
use anchor_lang::system_program::{create_account, CreateAccount};
use anchor_spl::{
    token_2022::{
        initialize_account3,
        spl_token_2022::{extension::ExtensionType, pod::PodAccount},
        InitializeAccount3,
    },
    token_interface::{memo_transfer_initialize, MemoTransfer, Mint, Token2022},
};

// 현재 MemoTransfer 익스텐션을 자동으로 초기화하는 Anchor 제약은 없습니다.
// instruction 핸들러에서 CPI를 통해 token account를 수동으로 생성하고 초기화할 수 있습니다.
pub fn initialize(ctx: Context<Initialize>) -> Result<()> {
    // token 및 익스텐션 데이터에 필요한 공간을 계산합니다.
    let token_account_size =
        ExtensionType::try_calculate_account_len::<PodAccount>(&[ExtensionType::MemoTransfer])?;

    // 익스텐션이 있는 token account 크기에 필요한 최소 lamports를 계산합니다.
    let lamports = (Rent::get()?).minimum_balance(token_account_size);

    // System Program을 호출하여 token account 및 익스텐션 데이터 공간이 있는 새 account를 생성합니다.
    create_account(
        CpiContext::new(
            ctx.accounts.system_program.to_account_info(),
            CreateAccount {
                from: ctx.accounts.payer.to_account_info(),
                to: ctx.accounts.token_account.to_account_info(),
            },
        ),
        lamports,                          // Lamports
        token_account_size as u64,         // Space
        &ctx.accounts.token_program.key(), // Owner Program
    )?;

    // 표준 token account 데이터를 초기화합니다.
    initialize_account3(CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        InitializeAccount3 {
            account: ctx.accounts.token_account.to_account_info(),
            mint: ctx.accounts.mint_account.to_account_info(),
            authority: ctx.accounts.payer.to_account_info(),
        },
    ))?;

    // memo transfer 익스텐션을 초기화합니다.
    // 이 instruction은 token account 초기화 다음에 와야 합니다.
    memo_transfer_initialize(CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        MemoTransfer {
            token_program_id: ctx.accounts.token_program.to_account_info(),
            account: ctx.accounts.token_account.to_account_info(),
            owner: ctx.accounts.payer.to_account_info(),
        },
    ))?;

    Ok(())
}

#[derive(Accounts)]
pub struct Initialize<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    #[account(mut)]
    pub token_account: Signer<'info>,
    pub mint_account: InterfaceAccount<'info, Mint>,
    pub token_program: Program<'info, Token2022>,
    pub system_program: Program<'info, System>,
}
```

<ArticleSection name="Transferring Token with a Memo" id="transferring-token-with-a-memo" level="h2" />

Solana에서 Memo 프로그램을 사용하려면 두 가지 실행 가능한 경로가 있습니다.

다음과 같이 우리만의 "raw" memo instruction을 구축하는 방법:

```ts
const message = "Hello, Solana";

new TransactionInstruction({
    keys: [{ pubkey: keypair.publicKey, isSigner: true, isWritable: true }],
    data: Buffer.from(message, "utf-8"), // Memo 메시지. 이 경우 "Hello, Solana"입니다.
    programId: new PublicKey("MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr"), // key와 memo 메시지를 검증하는 Memo 프로그램
}),
```

또는 다음과 같이 패키지를 다운로드한 후 Memo 프로그램 SDK를 사용할 수 있습니다:

```
npm i @solana/spl-memo
```

> memo를 생성한 후, 다음 instruction은 간단한 transfer instruction이 될 것입니다.

이 예시에서는 두 번째 옵션을 사용할 것이며, 다음과 같습니다:

```ts
const memoInstruction = createMemoInstruction(
    "Hello, world!",
    [keypair.publicKey],
);

//...transfer instruction을 포함하는 anchor instruction

const transferTransaction = new Transaction().add(
    memoInstruction,
    transferInstruction,
);

const transferSignature = await sendAndConfirmTransaction(connection, transferTransaction, [keypair]);

console.log(`memo와 함께 토큰이 transfer되었습니다! 여기에서 TX를 확인하세요: https://explorer.solana.com/tx/${transferSignature}?cluster=devnet`);
```

<ArticleSection name="Disabling and Enabling the Memo" id="disabling-and-enabling-the-memo" level="h2" />

transfer에 memo가 포함되도록 강제하고 싶지 않다면, memo_transfer_disable 함수를 사용하여 그렇게 할 수 있으며, 다음과 같습니다:

```rust
use anchor_lang::prelude::*;
use anchor_spl::token_interface::{memo_transfer_disable, MemoTransfer, Token, Mint, Token2022};

#[derive(Accounts)]
pub struct DisableMemo<'info> {
    #[account(mut)]
    pub owner: Signer<'info>,

    #[account(
        mut,
        token::authority = owner,
    )]
    pub token_account: InterfaceAccount<'info, TokenAccount>,
    pub token_program: Program<'info, Token2022>,
}

pub fn disable_memo(
    ctx: Context<DisableMemo>,
) -> Result<()> {
    memo_transfer_disable(CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        MemoTransfer {
            token_program_id: ctx.accounts.token_program.to_account_info(),
            account: ctx.accounts.token_account.to_account_info(),
            owner: ctx.accounts.owner.to_account_info(),
        },
    ))?;
    
    Ok(())
}
```
