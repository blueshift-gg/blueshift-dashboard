# CpiGuard 확장

`CpiGuard` 확장은 `Token` account 확장 기능으로, cross-program invocations 내에서 특정 작업을 금지하여 사용자의 명시적인 동의 없이 token account를 조작하려는 악성 프로그램으로부터 사용자를 보호합니다.

> 안타깝게도 CPI를 통해 CpiGuard 확장을 초기화하거나 업데이트할 수 없습니다. 더 자세한 내용은 [여기](https://github.com/solana-labs/solana-program-library/blob/6968859e2ee0a1764da572de340cdb58e2b4586f/token/program-2022/src/extension/cpi_guard/processor.rs#L44-L46)를 참조하십시오.
