# A Extensão Cpi Guard

A extensão `CpiGuard` é uma extensão de conta `Token` que proíbe certas ações dentro de invocações entre programas (cross-program invocations), protegendo os usuários de programas maliciosos que possam tentar manipular suas contas de token sem consentimento explícito.

> Infelizmente, não é possível inicializar ou atualizar a extensão CpiGuard através de uma CPI. Para mais informações, leia [isto](https://github.com/solana-labs/solana-program-library/blob/6968859e2ee0a1764da572de340cdb58e2b4586f/token/program-2022/src/extension/cpi_guard/processor.rs#L44-L46)
