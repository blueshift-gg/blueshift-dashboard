# The Token2022 Program

![Token 2022 with Anchor](/graphics/course-banners/token-2022-with-anchor.png)

Token2022 프로그램은 Token Extensions라고도 알려져 있으며, Token Program이 제공하는 기능의 상위 집합입니다.

어떤 추가 기능들이 제공되는지, 그리고 Legacy token program과의 차이점에 대해 더 자세히 알아보려면, [이 과정](/en/courses/token-2022-program)을 수강해 보세요.

> Anchor에 익숙하지 않다면, 계속 진행하기 전에 저희의 [Anchor for Dummies](/en/courses/anchor-for-dummies) 과정을 수강하시는 것을 권장합니다.

Anchor의 경우, 토큰 관련 모든 내용은 `anchor-spl` crate에서 찾을 수 있습니다. 이 때문에 `Anchor` workspace를 초기화한 후에는 다음과 같이 할 수 있습니다:

```bash
cargo add anchor-spl
```

> `anchor-spl`의 버전은 `anchor-lang` crate의 버전과 동일해야 합니다. 그리고 Token2022 Extensions는 버전 0.30.0부터만 사용할 수 있습니다.

이후 프로그램의 `Cargo.toml` 파일의 `[features]` 섹션에 있는 `idl-build` 기능을 `idl-build = ["anchor-lang/idl-build", "anchor-spl/idl-build"]`로 업데이트하는 것을 잊지 마세요.

<ArticleSection name="Mint and Token Accounts" id="mint-and-token-accounts" level="h2" />

`Anchor`에 익숙하다면, account 초기화와 관련된 많은 복잡성을 추상화하는 데 도움이 되는 macro 집합이 있다는 것을 알 것입니다.

여기서도 `Mint`, `Token`, `Associated Token` account에 동일하게 적용됩니다.

### Extension이 있는 Mint Account

`Mint` account가 extension을 포함하면 크기가 다르고 다른 program에 의해 소유되므로, `Anchor`는 `Mint` account가 Legacy Token 프로그램에서 온 것이든 Token2022 프로그램에서 온 것이든 상관없이 작동하는 새로운 유형의 account를 만들었습니다.

이를 사용하려면 다음과 같이 `anchor_spl::token_interface`에서 `TokenInterface`와 `Mint`를 모두 import하면 됩니다:

```rust
use anchor_spl::token_interface::{TokenInterface, Mint};
```

그 후에는 `pub mint: InterfaceAccount<'info, Mint>,`와 같이 선언하고 account struct에 있는 `token_program` account를 mint가 사용하도록 `mint::token_program = token_program`과 같이 지정하기만 하면 됩니다!

> token interface는 역직렬화(deserialization) 로직의 차이를 처리할 필요 없이 두 가지 유형의 account와 상호작용할 수 있는 공통적인 방법을 제공하며, type safety와 적절한 유효성 검사를 유지합니다.

mint account에 extension을 추가하는 방법을 살펴보기 전에, Token2022 프로그램으로 mint를 생성하는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateMint<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    #[account(
        init,
        payer = signer,
        mint::decimals = 6,
        mint::authority = signer.key(),
        mint::token_program = token_program
    )]
    pub mint: InterfaceAccount<'info, Mint>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

다행히도 `Anchor`는 가장 인기 있는 extension들을 초기화 단계에서 직접 추가할 수 있도록 macro를 만들었습니다. 다음과 같습니다:

```rust
#[account(
    // ...init
    extensions::metadata_pointer::authority = <target_account>,
    extensions::metadata_pointer::metadata_address = <target_account>,
    extensions::group_pointer::authority = <target_account>,
    extensions::group_pointer::group_address = <target_account>,
    extensions::group_member_pointer::authority = <target_account>,
    extensions::group_member_pointer::member_address = <target_account>,
    extensions::transfer_hook::authority = <target_account>,
    extensions::transfer_hook::program_id = <target_pubkey>
    extensions::close_authority::authority = <target_account>,
    extensions::permanent_delegate::delegate = <target_account>,
)]
pub mint: InterfaceAccount<'info, Mint>,
```

### Extension이 있는 Associated Token Account

`Associated Token` account는 기본적으로 `ImmutableOwner` extension을 포함합니다. 따라서 Legacy 또는 Token2022 `Token Account` 생성의 유일한 차이점은 `Interface Account`의 사용 여부입니다.

associated token account를 생성하는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateAssociatedToken<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    pub mint: InterfaceAccount<'info, Mint>,
    #[account(
        mut,
        associated_token::mint = mint,
        associated_token::authority = signer,
        associated_token::token_program = token_program,
    )]
    pub associated_token: InterfaceAccount<'info, TokenAccount>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

### Extension이 있는 Token Account

`Token` account는 기본적으로 어떤 extension도 포함하지 않으며, 우리에게 도움이 되는 macro도 없습니다. 따라서 macro를 사용하면 일반적인 Token2022 `Token` account만 생성할 수 있습니다.

token account를 생성하는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateToken<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    pub mint: InterfaceAccount<'info, Mint>,
    #[account(
        mut,
        token::mint = mint,
        token::authority = signer,
        token::token_program = token_program,
    )]
    pub token: InterfaceAccount<'info, TokenAccount>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```
