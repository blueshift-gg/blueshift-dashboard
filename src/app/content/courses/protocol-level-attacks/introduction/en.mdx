# Protocol-Level Attacks

Individual bugs are dangerous. But the attacks that drain protocols and make headlines rarely exploit a single vulnerability in isolation. They chain together multiple weaknesses, using the composability of DeFi itself as an attack surface. A stale oracle becomes a mispricing. A mispricing enables an arbitrage. An arbitrage, amplified by a flash loan, becomes a multi-million dollar extraction.

This course moves beyond single-instruction vulnerabilities into the territory of protocol-level exploits: attacks that target the economic logic, state management, and composability assumptions of Solana programs operating in production.

<ArticleSection name="From Bugs to Exploits" id="from-bugs-to-exploits" level="h2" />

A missing signer check is a bug. A missing signer check that allows an attacker to drain a lending protocol's reserves is an exploit. The distinction matters because it shapes how you think about security.

The Program Security course covered instruction-level defenses: owner checks, signer verification, type cosplay, and the other validations that prevent individual instructions from being misused. The Arithmetic and Accounting course covered the math underneath those instructions: overflow, rounding, fee compounding, and share calculation errors. Protocol-level security is the next layer. It prevents entire systems from being economically manipulated, even when every individual instruction is validated correctly and every calculation is arithmetically sound.

Consider a lending protocol where every account validation is correct, every signer is verified, every PDA is derived properly. The program is "secure" at the instruction level. But if it prices collateral using a single Pyth oracle feed without staleness checks, an attacker can wait for the oracle to lag behind the real market price, deposit overvalued collateral, borrow against it, and extract real value from the protocol.

No instruction-level bug was exploited. The protocol's economic assumptions were.

<ArticleSection name="What This Course Covers" id="what-this-course-covers" level="h2" />

This course examines six categories of protocol-level attacks:

1. **Oracle Manipulation** -- Exploiting price feed trust models, staleness windows, and confidence intervals to trigger mispricing
2. **First Depositor and Share Attacks** -- Manipulating vault share calculations through inflation, donation attacks, and rounding exploitation
3. **Flash Loan Attack Patterns** -- Using atomic composability as a weapon to amplify vulnerabilities and manipulate state within a single transaction
4. **State and Timing Vulnerabilities** -- Exploiting stale state, TOCTOU conditions, and cross-program state dependencies
5. **Denial of Service Vectors** -- Causing panics, resource exhaustion, and permanently locked funds through griefing
6. **Front-Running and MEV on Solana** -- Using transaction ordering, Jito bundles, and leader schedule knowledge for value extraction

Each lesson follows a consistent structure: vulnerable code first, attack explanation second, fix third. You will see specific numbers, real reference points from production protocols, and concrete mitigation patterns.

The goal is not just to understand these attacks in the abstract. It is to recognize them in code, reason about their economic impact, and build protocols that resist them from day one.
