# Default Account State Extension

`DefaultAccountState` extension은 특정 mint에 대해 새로 생성된 모든 `Token` account가 기본적으로 frozen되도록 허용하는 Mint extension입니다. Mint의 `Freeze Authority`는 이러한 `Token` account를 thaw(unfreeze)하여 사용할 수 있도록 할 수 있습니다.

<ArticleSection name="Initializing the Mint Account" id="initializing-the-mint-account" level="h2" />

`Mint` account에 `DefaultAccountState` extension을 initialize하려면 `initializeDefaultAccountState()` 함수가 필요합니다.

`Default Account State` extension을 사용하여 mint를 생성하는 방법은 다음과 같습니다:

```ts
import {
    Keypair,
    SystemProgram,
    Transaction,
    sendAndConfirmTransaction,
}
from '@solana/web3.js';
import {
    createInitializeMintInstruction,
    createInitializeDefaultAccountStateInstruction,
    getMintLen,
    ExtensionType,
    TOKEN_2022_PROGRAM_ID,
} from '@solana/spl-token';

const mint = Keypair.generate();

// Calculate the size needed for a Mint account with Default Account State extension
const mintLen = getMintLen([ExtensionType.DefaultAccountState]);

// Calculate minimum lamports required for rent exemption
const lamports = await connection.getMinimumBalanceForRentExemption(mintLen);

// Create the account with the correct size and owner
const createAccountInstruction = SystemProgram.createAccount({
    fromPubkey: keypair.publicKey,
    newAccountPubkey: mint.publicKey,
    space: mintLen,
    lamports,
    programId: TOKEN_2022_PROGRAM_ID,
});

// Initialize the Default Account State extension
const initializeDefaultAccountState = createInitializeDefaultAccountStateInstruction(
    mint.publicKey,
    AccountState.Frozen,
    TOKEN_2022_PROGRAM_ID,
);

// Initialize the mint itself
const initializeMintInstruction = createInitializeMintInstruction(
    mint.publicKey,
    6,
    keypair.publicKey,
    keypair.publicKey, // freeze authority is MANDATORY
    TOKEN_2022_PROGRAM_ID,
);

// Combine all instructions in the correct order
const transaction = new Transaction().add(
    createAccountInstruction,
    initializeDefaultAccountState,
    initializeMintInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair, mint]);

console.log(`Mint created! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

> 이 extension에서는 `Mint`의 `Freeze Authority`가 필수적이라는 점을 기억하세요. 그렇지 않으면 생성 시 어떤 `Token` account도 thaw할 수 없습니다.

<ArticleSection name="Thawing the Token Account" id="thawing-the-token-account" level="h2" />

`DefaultAccountState` extension이 있다는 것은 initialize되는 모든 `Token` account가 기본적으로 `frozen`된다는 것을 의미합니다.

이는 해당 `Token` account를 thaw(unfreeze)하지 않으면 `Mint`, `Transfer` 또는 그 어떤 작업도 할 수 없다는 것을 의미합니다.

`thawAccount` instruction을 사용하여 `Token` account를 쉽게 thaw할 수 있습니다:

```ts
const ata = await getAssociatedTokenAddress(
    mint.publicKey,
    keypair.publicKey,
    false,
    TOKEN_2022_PROGRAM_ID
);

const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    ata, // associated token account address
    keypair.publicKey, // owner
    mint.publicKey, // mint
    TOKEN_2022_PROGRAM_ID
)

const thawAtaInstruction = createThawAccountInstruction(
    ata,
    mint.publicKey,
    keypair.publicKey,
    undefined,
    TOKEN_2022_PROGRAM_ID,
);

const transaction = new Transaction().add(
    createAtaInstruction,
    thawAtaInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair], {skipPreflight: true});

console.log(`Token accounts created and thawed! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="Changing the Default Account State" id="changing-the-default-account-state" level="h2" />

토큰 분배에 대한 더 큰 통제가 필요 없고 모든 사람이 토큰을 자유롭게 거래하도록 하고 싶을 때, 다음과 같이 `updateDefaultAccountState` instruction을 사용하여 기본 account 상태를 변경할 수 있습니다:

```ts
const updateDefaultAccountStateInstruction = createUpdateDefaultAccountStateInstruction(
    mint.publicKey,
    AccountState.Initialized,
    keypair.publicKey,
    undefined,
    TOKEN_2022_PROGRAM_ID,
);

const transaction = new Transaction().add(updateDefaultAccountStateInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Default account state changed! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```
