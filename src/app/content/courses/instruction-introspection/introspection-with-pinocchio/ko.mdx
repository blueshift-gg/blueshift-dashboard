# Pinocchio를 사용한 인스트럭션 인트로스펙션

Pinocchio는 `solana_program` crate와는 다른 타입을 사용합니다. 이는 Pinocchio에 최적화된 새로운 SDK를 만들어야 했음을 의미합니다.

[Orion](https://x.com/BasedOrion_)의 도움으로, 우리는 "원본" 구현을 존중하면서도 — 사용 비용이 가장 비싼 sysvar 중 하나인 — `Instruction` sysvar를 가장 효율적인 것 중 하나로 만든 헬퍼 세트를 만들었습니다.

이러한 이유로, 우리는 Pinocchio에서 외부 crate를 설치할 필요 없이 *인스트럭션 인트로스펙션*을 사용할 수 있으며, 이 함수들을 임포트하여 필요한 모든 정보에 접근할 수 있습니다:

```rust
use pinocchio::sysvars::instructions::Instructions;
```

<ArticleSection name="How to use Introspection" id="how-to-use-introspection" level="h2" />

앞서 언급했듯이, 인스트럭션 인트로스펙션은 `Instruction` sysvar account의 데이터를 단순히 역직렬화하여 우리의 인스트럭션에 대해 필요한 모든 데이터를 제공합니다.

우리는 현재 인덱스를 확인하는 것으로 시작합니다. 이는 `load_current_index_checked` 함수를 사용하여 다음과 같이 수행할 수 있습니다:

```rust
let instruction_sysvar = unsafe { Instructions::new_unchecked(&self.accounts.sysvar_instructions.try_borrow_data()?) };
let index = instruction_sysvar.load_current_index();
```

그 다음으로, 우리는 `load_instruction_at_checked`를 사용하여 상대 인덱스에 있는 인스트럭션을 확인할 수 있습니다. 이번에는 인트로스펙션을 수행하는 인스트럭션 바로 다음에 오는 인스트럭션을 다음과 같이 확인할 것입니다:

```rust
// We load the next instruction, which is the one we want to check for the correct input.
let instruction = instruction_sysvar.load_instruction_at(index as usize + 1)?;
```

다음 단계로 넘어가기 전에, 악의적인 공격을 방지하기 위해 어떤 정보가 필수적인지 스스로에게 물어봐야 합니다.

우리는 일반적으로 사용 중인 program이 우리가 예상하는 program인지 확인하는 것으로 시작합니다. 이 예시에서는 system program으로부터 다른 인스트럭션을 인트로스펙션하고 있으므로 다음과 같이 할 수 있습니다:

```rust
if instruction.get_program_id() != &pinocchio_system::ID {
    return Err(ProgramError::InvalidInstructionData);
}
```

다음으로, 우리는 인스트럭션이 우리가 예상하는 것인지 확인합니다. 이를 위해 discriminator와 instruction data를 예상 값과 비교합니다. 우리는 `instruction_data` 변수를 생성하고 이를 확인하는 것으로 시작하며, 다음과 같습니다:

```rust
let mut instruction_data = [0u8; 12];
instruction_data[0..4].copy_from_slice(&2u32.to_le_bytes());
instruction_data[4..12].copy_from_slice(&100_000_000u64.to_le_bytes());

if instruction.get_instruction_data() != instruction_data {
    return Err(ProgramError::InvalidInstructionData);
}
```

우리는 그 다음 확인하고 있는 인스트럭션의 로직에 따라 더 많은 program별 확인을 수행할 수 있습니다.

우리는 또한 인트로스펙션된 인스트럭션에 존재하는 account들을 확인할 수 있습니다. 이 단계는 특정 인덱스에 있는 account의 data 또는 pubkey를 요청할 것이기 때문에 우리가 account struct의 정확한 구조를 알아야 합니다. 예를 들면 다음과 같습니다:

```rust
if !pubkey_eq(instruction.get_account_meta_at(0)?.key(), self.accounts.from.key()) {
    return Err(ProgramError::InvalidAccountData);
}
```
