# 전송 Instruction

토큰을 한 account에서 다른 account로 이동합니다. 이는 사용자 간에 토큰을 전송하는 기본적인 작업입니다.

토큰을 전송하기 전에 다음이 준비되어 있어야 합니다:
- `Mint` account가 초기화되어 있어야 합니다.
- 전송하려는 양 이상의 토큰을 이미 보유하고 있는 소스 `Token` account 또는 `Associated Token` account.
- 소스 `Token` account로부터 토큰을 받을 대상 `Token` account 또는 `Associated Token` account.

> 전송하는 토큰의 양은 decimals에 대해 "정규화"됩니다. 즉, 6 decimals를 가진 토큰 1개를 전송하려면 실제로는 `1_000_000`을 양으로 입력해야 합니다.

다음은 `transfer()` instruction에 대한 CPI가 어떻게 생겼는지 보여줍니다:

```rust
transfer(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Transfer {
            from: ctx.accounts.from_token_account.to_account_info(),
            to: ctx.accounts.to_token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```
