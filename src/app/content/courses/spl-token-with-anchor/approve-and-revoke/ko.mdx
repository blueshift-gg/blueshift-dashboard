# 승인 및 해지 명령어

승인(Approve)은 account 소유자를 대신하여 특정량의 토큰을 전송할 수 있는 권한을 delegate에게 부여합니다. 이는 account에 대한 완전한 제어권을 넘겨주지 않고도 프로그램 방식의 토큰 전송을 가능하게 합니다.

> 우리는 "승인된(approved)" 금액을 설정하며, delegate는 해당 금액까지만 전송할 수 있습니다.

해지(Revoke)는 현재 delegate가 account에 대해 가지고 있는 권한을 제거하여, account 소유자에게 완전한 제어권을 돌려줍니다.

> 기존의 모든 위임(delegation)을 즉시 취소하며, account 소유자만 위임을 해지할 수 있습니다 (delegate 자체는 해지할 수 없습니다).

토큰 account를 위임(delegate)하거나 해지(revoke)하기 전에, 다음을 이미 가지고 있어야 합니다:
- `Mint` account를 초기화했습니다.
- 우리가 제어할 `Token` account 또는 `Associated Token` account를 초기화했습니다.

> 우리가 발행(mint)하는 토큰의 양은 소수점(decimals)에 대해 "정규화(normalized)"됩니다. 이는 만약 우리가 6개의 소수점을 가진 토큰 1개를 발행하려면, 실제로는 `1_000_000`을 양(amount)으로 입력해야 함을 의미합니다.

`approve()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
approve(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Approve {
            to: ctx.accounts.token_account.to_account_info(),
            delegate: ctx.accounts.delegate.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```

그리고 `revoke()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
revoke(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Revoke {
            pub source: ctx.accounts.token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```
