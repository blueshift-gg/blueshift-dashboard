# Burn Instruction

토큰을 유통량에서 영구적으로 제거하여 파괴합니다. 이는 토큰의 총 공급량을 감소시킵니다.

어떤 토큰이든 소각하기 전에 다음을 미리 준비해야 합니다:
- `Mint` account가 초기화되어 있어야 합니다.
- 소각하려는 양 이상의 토큰을 보유한 `Token` account 또는 `Associated Token` account가 있어야 합니다.

> 우리가 소각하는 토큰의 양은 소수점(decimals)에 맞춰 "정규화"됩니다. 즉, 6개의 소수점을 가진 토큰 1개를 소각하려면, 실제로는 `1_000_000`을 `amount`로 입력해야 합니다.

`burn()` instruction에 대한 CPI는 다음과 같습니다:

```rust
burn(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Burn {
            mint: ctx.accounts.mint.to_account_info(),
            from: ctx.accounts.token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```
