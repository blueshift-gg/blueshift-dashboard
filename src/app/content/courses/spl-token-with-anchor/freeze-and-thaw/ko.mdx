# Freeze 및 Thaw 명령어

Freeze는 계정(account)이 thawed될 때까지 모든 토큰(token) 작업을 방지합니다. 이 작업은 민트(mint)의 freeze authority만 수행할 수 있습니다.

> 전송(transfer), 승인(approval), 소각(burn)을 완전히 비활성화하며, 특정 frozen된 계정(account)에만 영향을 미칩니다.

Thaw는 이전에 frozen된 계정(account)에서 토큰(token) 작업을 다시 활성화합니다. 민트(mint)의 freeze authority만이 계정(account)을 thaw할 수 있습니다.

> frozen된 계정(account)의 모든 기능을 복원하며, 민트(mint)의 freeze authority만 수행할 수 있습니다.

어떤 토큰(token) 계정(account)이든 freeze하거나 thaw하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- `freezeAuthority`를 보유한 `Mint` account를 초기화해야 합니다.
- freeze하거나 thaw하려는 `Token` account 또는 `Associated Token` account를 초기화해야 합니다.

다음은 `freeze_account()` instruction에 대한 CPI가 어떻게 보이는지 보여줍니다:

```rust
freeze_account(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        FreezeAccount {
            account: ctx.accounts.token_account.to_account_info(),
            mint: ctx.accounts.mint.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```

그리고 다음은 `thaw_account()` instruction에 대한 CPI가 어떻게 보이는지 보여줍니다:

```rust
thaw_account(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        ThawAccount {
            account: ctx.accounts.token_account.to_account_info(),
            mint: ctx.accounts.mint.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```
