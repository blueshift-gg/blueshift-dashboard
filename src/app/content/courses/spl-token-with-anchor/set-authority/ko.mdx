# Set Authority Instructions

mint 또는 account의 권한을 변경합니다. 이를 통해 소유권을 이전하거나 특정 권한 유형을 업데이트할 수 있습니다.

어떤 token 또는 token account의 권한을 설정하기 전에, 우리는 이미 다음을 가지고 있어야 합니다:
- `mintAuthority` 또는 `freezeAuthority`를 보유하고 있는 `Mint` account를 초기화해야 합니다.
- 우리가 소유하고 있는 `Token` account 또는 `Associated Token` account를 초기화해야 합니다.

`set_authority()` instruction으로의 CPI는 다음과 같습니다:

```rust
set_authority(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        SetAuthority {
            account_or_mint: ctx.accounts.mint_account.to_account_info(),
            to: ctx.accounts.to_token_account.to_account_info(),
            current_authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &spl_token::instruction::AuthorityType::MintTokens, // authority_type
    Some(new_authority.key()) // new_autority
)?;
```
