# 계정 폐쇄 지침

토큰 계정을 닫고 남은 SOL 렌트비를 대상 계정으로 전송합니다. 해당 토큰 계정은 네이티브 SOL 계정이 아닌 한 잔액이 0이어야 합니다.

> Token2022부터는 공급량(supply)이 0인 `Mint` account를 닫을 수 있습니다.

토큰 계정을 닫기 전에 다음을 미리 준비해야 합니다:
- `Mint` account를 초기화했습니다.
- 토큰이 없는 `Token` account 또는 `Associated Token` account를 초기화했습니다.

`close_account()` 지침에 대한 CPI는 다음과 같습니다:

```rust
close_account(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        CloseAccount {
            account: ctx.accounts.token_account.to_account_info(),
            destination: ctx.accounts.authority.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```
