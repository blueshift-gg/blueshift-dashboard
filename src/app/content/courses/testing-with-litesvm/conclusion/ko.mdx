# 결론

축하합니다! LiteSVM으로 테스트하기 과정을 완료하셨습니다. 이제 여러분은 LiteSVM을 사용하는 방법에 대해 포괄적인 이해를 갖게 되었습니다. LiteSVM은 Solana Virtual Machine을 테스트 프로세스에 직접 통합하여 빠른 반복 작업과 정밀한 프로그램 테스트를 가능하게 하는 빠르고 가벼운 테스트 프레임워크입니다.

<ArticleSection name="What you've learned" id="what-you-learned" level="h2" />

이 과정을 통해 여러분은 LiteSVM의 필수 개념들을 익혔습니다:
- **성능 이점**: LiteSVM의 인-프로세스 VM이 기존 테스트 프레임워크보다 훨씬 빠른 실행을 제공하는 방법
- **Account 관리**: 포괄적인 테스트 시나리오를 위해 system accounts, program accounts, 그리고 SPL token accounts를 생성하고 구성하는 방법
- **Transaction 실행**: 적절한 결과 검사와 함께 transaction을 설정하고, 시뮬레이션하며, 실행하는 방법
- **고급 제어**: sysvars를 조작하고, 런타임 동작을 제어하며, 테스트 환경을 커스터마이징하는 방법

<ArticleSection name="Next Steps" id="next-steps" level="h2" />

이제 LiteSVM을 사용하여 Solana 프로그램에 대한 빠르고 신뢰할 수 있는 테스트를 구축할 준비가 되셨습니다! 다음은 권장되는 다음 단계입니다:
1. 프로젝트에 적용: 기존 Solana 프로그램 테스트 스위트에 LiteSVM을 통합하고 성능 향상을 직접 경험해 보세요.
2. 고급 테스트 탐색: LiteSVM의 account 조작 기능을 사용하여 다른 프레임워크로는 재현하기 어려운 복잡한 엣지 케이스 및 실패 시나리오를 테스트하세요.
3. 성능 벤치마크: LiteSVM의 속도를 활용하여 개발 및 CI/CD pipelines 중에 포괄적인 테스트 스위트를 실행하세요.
4. 커뮤니티 참여: Discord에서 LiteSVM을 사용하는 다른 개발자들과 연결하여 테스트 전략 및 최적화 방법을 공유하세요.
5. 최신 정보 확인: 최신 기능, 언어 바인딩 및 성능 향상을 위해 [LiteSVM 저장소](https://github.com/LiteSVM/litesvm)를 팔로우하세요.
