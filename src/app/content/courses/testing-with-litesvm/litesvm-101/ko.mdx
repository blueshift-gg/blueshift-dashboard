# LiteSVM 101

![LiteSVM으로 테스트하기](/graphics/course-banners/testing-with-litesvm.png)

Solana 프로그램 테스트는 전통적으로 속도와 정확성 중 하나를 선택해야 했습니다. LiteSVM은 매우 빠르고 기능적으로 완전한 인-프로세스 테스트 환경을 제공함으로써 이러한 절충점을 없앱니다.

LiteSVM은 Solana 개발자들에게 세 가지 중요한 이점을 제공합니다:
- `solana-program-test` 및 `solana-test-validator` 대비 **더 빠른 실행**
- 복잡한 엣지 케이스 테스트를 위한 **직접적인 account 상태 조작**
- 최적화 및 개선점 식별을 위한 **내장된 성능 프로파일링**

<ArticleSection name="What is LiteSVM" id="what-is-litesvm" level="h2" />

[LiteSVM](https://github.com/LiteSVM/litesvm)은 경량 Solana Virtual Machine으로, 테스트 프로세스에서 직접 실행됩니다. [Exotic Markets](https://x.com/exotic_markets_)의 [Aursen](https://x.com/exoaursen)이 개발했으며, 외부 validator의 오버헤드를 없애고 Solana 런타임과의 완벽한 호환성을 유지합니다.

별도의 validator 프로세스를 생성하는 전통적인 테스트 방식과 달리, LiteSVM은 VM을 테스트 내부에 포함시킵니다. 이 아키텍처는 테스트 정확성을 희생하지 않으면서도 컴파일 및 실행 시간을 획기적으로 단축시킵니다.

이 라이브러리는 빠른 설정을 위한 직관적인 API와 스마트한 기본값을 제공하며, 고급 테스트 시나리오를 위한 광범위한 구성 옵션도 갖추고 있습니다.

> LiteSVM은 Rust, TypeScript/JavaScript, Python (`solders`를 통해)을 지원합니다.
