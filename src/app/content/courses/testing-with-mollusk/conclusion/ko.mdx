# 결론

축하합니다! Mollusk를 사용한 테스트 과정을 완료했습니다. 이제 Solana 프로그램용 강력하고 가벼운 테스트 프레임워크인 Mollusk를 사용하는 방법에 대한 포괄적인 이해를 갖게 되었습니다. Mollusk는 빠른 실행, 정밀한 제어, 상세한 성능 인사이트를 제공합니다.

<ArticleSection name="What you've learned" id="what-you-learned" level="h2" />

이 과정을 통해 다음과 같은 필수 지식을 습득했습니다:
- Mollusk가 로우레벨 Solana Virtual Machine (SVM) 컴포넌트를 사용하여 간소화된 테스트 환경을 제공하는 방법
- 완전한 validator 시뮬레이션 대비 Mollusk의 경량(lightweight) 접근 방식의 장점
- 핵심 `mollusk-svm` crate 및 프로그램별 헬퍼를 사용하여 Mollusk를 설정하는 방법
- 단일 및 연결된 instruction 테스트를 위한 Mollusk의 네 가지 주요 실행 API 사용
- success conditions, compute units, account states에 대한 포괄적인 validation check 구현
- 사전 초기화된 token account (Mints, Token Accounts, Associated Token Accounts) 생성
- `MolluskComputeUnitBencher`를 사용한 compute unit 소비량 벤치마킹
- 특수 기능(specialized functionality)을 위한 커스텀 syscall 개발 및 테스트
- compute budgets, feature sets, sysvars를 통한 실행 환경 커스터마이징

<ArticleSection name="Next Steps" id="next-steps" level="h2" />

이제 Mollusk를 사용하여 견고하고 잘 테스트된 Solana 프로그램을 구축할 수 있는 지식을 갖추게 되었습니다! 다음은 권장되는 다음 단계입니다:
1. 실제 프로그램으로 연습하기: Mollusk 지식을 적용하여 [Anchor Programs](/en/courses/anchor-for-dummies/testing-your-program#mollusk-tests) 또는 [Pinocchio Programs](/en/courses/introduction-to-pinocchio/testing-your-program#mollusk-tests)를 테스트하세요.
2. 챌린지 탐색: Mollusk 테스트 기술을 적용하는 데 도움이 될 실습을 위해 [Challenges 섹션](/en/challenges)을 방문하세요.
3. 커뮤니티 참여: Mollusk를 사용하는 다른 개발자들과 연결하여 테스트 전략 및 모범 사례를 저희 discord에서 공유하세요.
4. 최신 정보 유지: 최신 기능 및 개선 사항을 위해 [Mollusk repository](https://github.com/anza-xyz/mollusk)를 팔로우하세요.
