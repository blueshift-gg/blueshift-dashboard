# Metaplex Token Metadata Program

Solana에서 토큰을 발행했는데, 모든 wallet에 '7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU'와 같이 의미 없는 문자열로만 나타난다고 상상해 보세요.

사용자들은 자신이 무엇을 가지고 있는지 전혀 알 수 없을 것이고, 여러분이 공들여 만든 프로젝트는 네트워크를 범람하는 수천 개의 다른 익명 토큰들과 구별할 수 없게 될 것입니다.

Metaplex Token Metadata Program은 익명의 blockchain entry들을 브랜드화되고 인식 가능한 디지털 asset으로 변환하여 이 중요한 문제를 해결합니다.

SPL-Token program은 소유권 추적, 공급 관리, 전송 용이화와 같은 기술적인 메커니즘에 뛰어나지만, 토큰들을 사람이 읽을 수 있는 어떤 문맥도 없는 기본적인 데이터 구조로 남겨둡니다.

이것이 Metaplex가 마법을 부리는 부분으로, 원시적인 blockchain 기능과 사용자 경험 사이의 간극을 메웁니다. 알 수 없는 address 대신, 사용자들은 익숙한 logo, 명확한 설명, 그리고 토큰을 실제 세계에서 실제로 사용할 수 있게 만드는 모든 문맥 정보와 함께 'Solana (SOL)'을 보게 됩니다.

`Metadata` account는 단순한 mint address를 인식 가능한 asset으로 변환하는 모든 정보를 저장하며, 여러분의 토큰의 디지털 신분증 역할을 합니다.

이것은 단지 예쁜 이름이나 그림에 관한 것이 아닙니다. 여러분의 토큰이 Solana ecosystem 전체에 어떻게 나타나는지에 대한 기반을 만드는 것입니다.

Solana의 Program Derived Address 시스템을 사용하여, 모든 토큰은 자신의 mint에 수학적으로 연결된 정확히 하나의 metadata account를 가집니다. 이것은 기술적인 토큰과 그 설명 정보 사이에 깨뜨릴 수 없는 결합을 만들어, 모든 application에서 일관성을 보장하고 신원 충돌을 방지합니다:

```rust
const ID: Pubkey = solana_pubkey::pubkey!("metaqbxxUerdq28cj1RbAWkYQm3ybzjb6a8bt518x1s");

const PREFIX: &str = "metadata";

let (metadata, _) = Pubkey::find_program_address(
    &[
        PREFIX.as_bytes(), 
        &ID, 
        mint.as_ref()
    ], 
    &ID  
);
```

metadata account는 여러분의 토큰의 범용 여권이 되어, application이 여러분의 asset을 올바르게 표시하기 위해 필요한 모든 것을 포함합니다.

토큰 이름은 이해할 수 없는 address를 대체하고, symbol은 즉각적인 인식을 제공하며 (위의 긴 문자열 대신 "SOL"을 떠올려 보세요), URI 참조는 logo 및 상세 설명과 같은 풍부한 미디어를 가리킵니다.

그 결과는? 여러분의 토큰은 단순히 blockchain에 존재하는 것이 아니라—wallet에서 번성하고, explorer에서 전문적으로 나타나며, Solana ecosystem 전반의 application과 원활하게 통합됩니다.

> `Token Metadata` program을 사용하는 방법에 대해 더 알아보려면, [공식 문서](https://developers.metaplex.com/token-metadata)를 참조하세요.
