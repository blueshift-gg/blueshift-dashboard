# Using Solana

You understand why Solana exists and how it works. Here's how to use a wallet, send transactions, explore the blockchain, and navigate the ecosystem.

Wallet equals key manager, not money storage. Your keys control your accounts. Block explorers show all on-chain data.

<ArticleSection name="Wallets: Managing Your Keys" id="wallets-managing-keys" level="h2" />

A Solana wallet does not store your cryptocurrency. The coins exist as entries on the blockchain. Your wallet stores private keys and helps create digital signatures to prove you can spend those coins.

Think of your wallet as a keychain for blockchain accounts.

**Popular Solana wallets:**

**Phantom:** Browser extension and mobile app. User-friendly interface. Supports tokens, NFTs, and staking. Most popular choice for new users.

**Solflare:** Browser extension and mobile app. Strong security features. Built-in hardware wallet support. Good for security-conscious users.

**Backpack:** Browser extension with integrated xNFT support. Modern UI. Developer-friendly.

All these wallets use the same underlying technology—they generate keypairs and sign transactions. You can use the same seed phrase to recover your accounts in any wallet.

**Setting up a wallet:**

1. Install the wallet extension or app
2. Create a new wallet (this generates a new private key)
3. **Critical:** Write down your seed phrase (12 or 24 words)
4. Store the seed phrase somewhere safe (not on your computer)
5. Your wallet address is now active and can receive SOL

**Seed phrases are everything:**

Your seed phrase is a human-readable representation of your private key. Anyone with your seed phrase controls all your accounts and assets.

Never:
- Share your seed phrase with anyone
- Enter it into websites claiming to "validate" it
- Store it in email, cloud storage, or screenshots
- Take photos of it

Always:
- Write it on paper
- Store it in a secure physical location
- Consider metal backup for fire/water protection
- Test recovery in a separate wallet with a small amount first

If you lose your seed phrase and your device breaks, your funds are gone forever. No customer support can recover them.

<ArticleSection name="Getting SOL" id="getting-sol" level="h2" />

To use Solana, you need SOL for transaction fees.

**Mainnet (real SOL):**

- **Centralized exchanges:** Buy SOL on Coinbase, Binance, Kraken, or other exchanges. Withdraw to your wallet address.
- **Decentralized exchanges:** Swap other cryptocurrencies for SOL on Jupiter, Raydium, or Orca.
- **On-ramps:** Use services like Moonpay or Transak to buy SOL directly with credit card.

**Devnet (test SOL):**

For testing without real money, use devnet:

```bash
# Install Solana CLI
sh -c "$(curl -sSfL https://release.solana.com/stable/install)"

# Configure for devnet
solana config set --url https://api.devnet.solana.com

# Request airdrop (test SOL)
solana airdrop 2

# Check balance
solana balance
```

Devnet SOL has no value. Use it for learning and testing applications before committing real funds.

<ArticleSection name="Sending a Transaction" id="sending-transaction" level="h2" />

Here's how to send SOL using Phantom wallet.

**Step 1: Open Phantom and ensure you have SOL**

Check your balance. You need at least 0.000005 SOL for the transaction fee, plus whatever amount you want to send.

**Step 2: Click Send**

Enter the recipient's Solana address or scan their QR code. Addresses look like: `7TpX...9kLM` (43 characters, base58 encoded).

**Step 3: Enter amount**

Specify how much SOL to send. The wallet shows the transaction fee (typically 0.000005 SOL).

**Step 4: Review and confirm**

Check:
- Recipient address is correct (sending to wrong address is irreversible)
- Amount is correct
- You have enough SOL for amount + fee

Click confirm. Your wallet signs the transaction with your private key.

**Step 5: Transaction processes**

The wallet broadcasts your signed transaction to the network. You'll see:
- "Pending" while the transaction propagates
- "Confirmed" when included in a block (usually 1-2 seconds)

**What just happened behind the scenes:**

1. Your wallet constructed a transaction containing a System Program `transfer` instruction
2. The transaction declared which accounts it would access (your account and recipient's account)
3. Your wallet signed the transaction with your private key
4. The wallet sent the signed transaction to an RPC node
5. The RPC node forwarded it to the current leader
6. The leader included it in a block
7. Validators confirmed the block
8. Your transaction is now final and irreversible

<ArticleSection name="Block Explorers" id="block-explorers" level="h2" />

Block explorers let you view all on-chain data. Everything on Solana is public and verifiable.

**Solana Explorer** (https://explorer.solana.com)

The official explorer. Clean interface showing:
- Transactions by signature
- Accounts by address
- Blocks by slot number
- Programs and their interactions

**Using Solana Explorer:**

1. Go to https://explorer.solana.com
2. Enter any transaction signature, account address, or block slot
3. View complete details

**What you can see:**

For transactions:
- All instructions executed
- Which accounts were accessed
- Which programs were called
- Success or failure status
- Compute units consumed
- Fee paid

For accounts:
- Current lamport balance
- Owner program
- Data size and rent status
- Complete transaction history
- Token holdings (if any)

**Solscan** (https://solscan.io)

Alternative explorer with enhanced UI:
- Better token display with icons and prices
- NFT galleries with images
- More user-friendly for non-technical users
- Analytics and statistics

Try viewing a famous transaction or account. Search for the USDC token mint address: `EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v`

You'll see its complete history, supply, and every holder.

<ArticleSection name="Understanding Transaction Signatures" id="understanding-transaction-signatures" level="h2" />

Every transaction has a unique signature—a 88-character base58 string like:

```
3nGq2yczqCpm8bF2dyvdPtXpnFLJ1gKWyPp4EYFS8k8wHqJLfcBBdpKYmKCKMJhpYcXqmLWdWcNQjTiJhHWMVdU5
```

This signature identifies the transaction and serves as a receipt. With the signature, you can:
- View the transaction on a block explorer
- Prove the transaction occurred
- Verify the transaction details

After sending a transaction, your wallet displays the signature. Copy it and search for it on a block explorer to see exactly what happened.

**Common transaction scenarios:**

- **Success:** Transaction processed, state updated, "Success" status shown
- **Failure:** Transaction included in a block but reverted due to program error. You still pay fees.
- **Dropped:** Transaction not included in a block within its timeout period. No fees paid. Need to retry.

<ArticleSection name="Your Next Steps" id="your-next-steps" level="h2" />

What comes next depends on your goals.

**Path 1: Build on Solana**

If you want to develop Solana programs:

1. **Learn Rust:** Solana programs are written in Rust. Learn the language fundamentals.
2. **Study Anchor:** The Anchor framework makes Solana development more accessible.
3. **Read Solana Cookbook:** Practical examples and patterns at https://solanacookbook.com
4. **Build small projects:** Start with simple programs like counters or note-taking apps.
5. **Study existing programs:** Read open-source code from successful protocols.
6. **Join the community:** Discord, Twitter, and forums have helpful developers.

Recommended learning path:
- Solana Cookbook (practical patterns)
- Anchor tutorial (framework basics)
- Program security course (vulnerabilities and best practices)
- Build something real (portfolio piece)

**Path 2: Use Solana Applications**

If you want to use DeFi, NFTs, or other applications:

1. **Start small:** Test with small amounts while learning
2. **Understand risks:** Smart contracts can have bugs. Start with established protocols.
3. **Learn DeFi basics:** Understand liquidity pools, impermanent loss, and yield farming before risking significant capital.
4. **Join communities:** Follow projects you use on Twitter and Discord.
5. **Diversify:** Don't put everything in one protocol or asset.

Safety practices:
- Verify contract addresses before interacting
- Revoke unnecessary token approvals
- Use hardware wallets for large amounts
- Be skeptical of promises that seem too good to be true
- Research projects thoroughly before investing

**Path 3: Contribute to Ecosystem**

If you want to contribute without programming:

- **Content creation:** Write tutorials, create videos, explain concepts
- **Community support:** Help newcomers in Discord and forums
- **Testing:** Test new applications and report bugs
- **Governance:** Participate in DAO governance for protocols you use
- **Advocacy:** Explain blockchain and Solana to others

<ArticleSection name="Key Takeaways" id="key-takeaways" level="h2" />

Blockchains replace trusted intermediaries with verifiable computation. Solana achieves this at scale through Proof of History, parallel execution, and its account model.

You can now use wallets to manage keys, send transactions, and explore on-chain data. The architecture combines stateless programs with parallel execution to process thousands of transactions per second.

The tools exist. The infrastructure works. The ecosystem continues to grow.
