# 계정 폐쇄 인스트럭션

토큰 account를 폐쇄하고 남은 SOL 대여 비용(rent)을 대상 account로 전송합니다. 해당 토큰 account는 native SOL account가 아닌 한 잔액이 0이어야 합니다.

> Token2022부터 공급량이 0인 `Mint` account를 폐쇄할 수 있습니다.

어떤 토큰 account든 폐쇄하기 전에, 다음을 미리 가지고 있어야 합니다:
- `Mint` account를 초기화했습니다.
- 토큰이 없는 `Token` account 또는 `Associated Token` account를 초기화했습니다.

<ArticleSection name="원시 인스트럭션" id="raw-instruction" level="h2" />

아무런 추상화 없이 "원시" 인스트럭션을 사용하면, account 폐쇄는 다음과 같이 보입니다:

```ts
// Delegate an ATA 
const closeAccountInstruction = createCloseAccountInstruction(
    tokenAccount // account
    keypair.publickey // destination
    keypair.publickey // authority
);

const transaction = new Transaction().add(closeAccountInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`토큰 account가 폐쇄되었습니다! TX는 여기에서 확인하세요: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 인스트럭션" id="abstracted-instruction" level="h2" />

`closeAccount()` 인스트럭션으로 추상화된 동일한 인스트럭션은 다음과 같이 보입니다:

```ts
  let tx = await closeAccount(
    connection,
    keypair,
    ata.address, // token Account
    keypair.publicKey, // destination
    keypair.publicKey, // authority
);

console.log(`성공적으로 폐쇄되었습니다! Transaction 여기: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
