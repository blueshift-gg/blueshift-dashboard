# Mint To 지시

새로운 토큰을 생성하여 지정된 account에 예치합니다. 오직 mint authority만이 이 작업을 수행할 수 있습니다.

토큰을 민트(mint)하기 전에, 다음을 미리 준비해야 합니다:
- `mintAuthority`를 보유하고 있는 `Mint` account를 초기화해야 합니다.
- 토큰을 민트할 `Token` account 또는 `Associated Token` account를 초기화해야 합니다.

> 우리가 민트하는 토큰의 양은 소수점 자릿수에 대해 "정규화"됩니다. 이는 6자리 소수점을 가진 토큰 1개를 민트하려면, 실제 `1e6`을 양으로 지정해야 함을 의미합니다.

<ArticleSection name="원시(Raw) 지시" id="raw-instruction" level="h2" />

어떤 추상화도 없이 "원시(raw)" 지시만을 사용하면, 토큰을 민트하는 방법은 다음과 같습니다:

```ts
const destination = Keypair.generate();

const tokenAccount = await getAssociatedTokenAddress(
    mint.publicKey,
    destination.publicKey,
);

// Create ATA creation instruction
const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    tokenAccount, // associated token account address
    destination.publicKey, // owner
    mint.publicKey, // mint
);

// Mint tokens to ATA 
const mintToInstruction = createMintToInstruction(
    mint.publicKey, // mint
    tokenAccount, // destination
    keypair.publicKey, // mint authority
    1_000e6, // amount of tokens
);

const transaction = new Transaction().add(
    createAtaInstruction,
    mintToInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token account가 생성되고 토큰이 민트되었습니다! 트랜잭션은 여기서 확인하세요: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 지시" id="abstracted-instruction" level="h2" />

동일한 지시를 `mintTo()` 지시로 추상화하면 다음과 같이 보입니다:

```ts
const destination = Keypair.generate();

const ata = await getOrCreateAssociatedTokenAccount(
    connection,
    keypair,
    mint,
    destination.publicKey
);

console.log(`당신의 ATA는 다음과 같습니다: ${ata.address}!`)
  
let tx = await mintTo(
    connection,
    keypair,
    mint,
    ata.address,
    keypair.publicKey,
    1e6,
);

console.log(`성공적으로 민트되었습니다! 트랜잭션은 여기서 확인하세요: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
