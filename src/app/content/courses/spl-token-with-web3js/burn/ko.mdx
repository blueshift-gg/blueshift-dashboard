# 토큰 소각 명령어

토큰을 유통에서 제거하여 영구적으로 파괴합니다. 이는 토큰의 총 공급량(total supply)을 감소시킵니다.

어떤 토큰이든 소각하기 전에 다음을 미리 준비해야 합니다:
- `Mint` account를 초기화했습니다.
- 소각하려는 양만큼 이상의 토큰을 이미 보유한 `Token` account 또는 `Associated Token` account.

> 소각하려는 토큰의 양은 decimals에 대해 "정규화(normalized)"됩니다. 즉, 6 decimals를 가진 토큰 1개를 소각하려면 실제로는 `1e6`을 양으로 입력해야 합니다.

<ArticleSection name="Raw Instruction" id="raw-instruction" level="h2" />

어떠한 추상화(abstraction) 없이 "raw" 명령어를 사용하면 토큰 소각은 다음과 같이 보일 것입니다:

```ts
// Burn tokens to ATA
const burnInstruction = createBurnInstruction(
    tokenAccount, // token account
    mint, // mint
    keypair.publicKey // owner
    1e6, // amount
);

const transaction = new Transaction().add(burnInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`토큰이 소각되었습니다! 여기서 TX를 확인하세요: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="Abstracted Instruction" id="abstracted-instruction" level="h2" />

`burn()` 명령어로 추상화된 동일한 명령어는 다음과 같이 보일 것입니다:

```ts
let tx = await burn(
    connection, // connection
    keypair, // payer
    tokenAccount, // token account
    keypair.publicKey, // owner of the token account
    1e6, // amount to transfer
);

console.log(`성공적으로 소각되었습니다! 트랜잭션은 여기서 확인하세요: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
