<ChallengeTitle>sBPF 어셈블리 슬리피지</ChallengeTitle>

이제 어셈블리 작성에 익숙해졌을 것이므로, 일반 계정만 사용하는 대신 슬리피지 검사가 SPL-Token과 Token2022 계정 모두에서 작동하도록 해야 합니다.

> `amount`는 예제와 동일한 상수로 메모리에 배치됩니다. 주요 차이점은 계정의 `data_len`가 동적이기 때문에 상수를 사용하여 명령어 데이터를 가져올 수 없다는 것입니다(명령어 데이터는 마지막 계정 데이터의 끝에 위치합니다).

하나의 명령어만 있는 프로그램을 만드세요. 다음을 수행해야 합니다:
- 단일 SPL 또는 Token2022 토큰 계정을 받습니다
- 명령어 데이터에서 u64(8바이트) 최소 잔액을 받습니다
- 최소 잔액에 대한 오프셋을 동적으로 계산합니다
- 슬리피지가 초과되면 `Slippage exceeded` 문자열을 로그하고 오류 코드 1을 반환합니다

> 올바른 명령어 데이터 오프셋을 얻으려면 [도구](https://sbpf.xyz)를 사용할 수 있습니다. 하지만 도움을 드리자면: 토큰 계정의 `data_len`는 `.equ TOKEN_ACCOUNT_DATA_LEN, 0x0058`에 있습니다

어셈블리 입문 과정의 [도구 섹션](/en/courses/introduction-to-assembly/tooling)에서 설명한 대로 sBPF 패키지를 설치하고 터미널에서 다음 명령어를 사용하여 프로그램을 빌드하세요:

```
sbpf build
```

이렇게 하면 `target/deploy` 폴더에 `.so` 파일이 생성됩니다.

이제 `take challenge` 버튼을 클릭하고 파일을 드롭하세요!
