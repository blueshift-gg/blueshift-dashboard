<ChallengeTitle>Anchor AMM</ChallengeTitle>

It's now time to put what you've learned to the test. Using what you've learned from the lesson, build an AMM program using the Anchor framework that satisfies the following requirements:

> Your state account should be defined using an account discriminator with a value of `1`.

<RequirementList>
  <Requirement title="Challenge 1: Initialize the pool">
    Your program should allow anyone to initialize a new liquidity pool with two tokens. Define an instruction to do this using an instruction discriminator with value `0`. The instruction should create the config account, LP mint, vaults for both tokens, and mint initial LP tokens to the initializer.
  </Requirement>

  <Requirement title="Challenge 2: Deposit liquidity">
    Your program should allow users to deposit both tokens into the pool and receive LP tokens in return. Define an instruction to do this using an instruction discriminator value of `1`. Include slippage protection with max_x and max_y parameters.
  </Requirement>

  <Requirement title="Challenge 3: Withdraw liquidity">
    Your program should allow LP token holders to burn their LP tokens and withdraw their proportional share of both tokens. Define an instruction to do this using an instruction discriminator value of `2`. Include slippage protection with min_x and min_y parameters.
  </Requirement>

  <Requirement title="Challenge 4: Swap tokens">
    Your program should allow users to swap one token for another using the constant product formula. Define an instruction to do this using an instruction discriminator value of `3`. Include slippage protection with a minimum output parameter.
  </Requirement>
</RequirementList>
