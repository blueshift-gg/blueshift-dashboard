<ChallengeTitle>Pinocchio AMM</ChallengeTitle>

Agora é hora de colocar o que você aprendeu em prática. Usando o que aprendeu na lição, construa um programa de AMM usando o framework Pinocchio que satisfaça os seguintes requisitos:

<RequirementList>
  <Requirement title="Desafio 1: Criando a conta `Config`">
    Seu programa deve permitir que um `initializer` crie uma conta `config` e crie uma conta `Mint` para seu token LP. Defina uma instrução para isso usando um discriminador de instrução com valor `0`.
  </Requirement>

<Requirement title="Desafio 2: Depositando no Amm">
  Seu programa deve permitir que um usuário deposite no pool de liquidez de um Amm e calcule a
  quantidade de tokens LP que receberá por sua contribuição. Defina uma instrução para isso usando
  um discriminador de instrução com valor `1`.
</Requirement>

<Requirement title="Desafio 3: Sacando do Amm">
  Seu programa deve permitir que um usuário saque do pool de liquidez de um Amm e calcule a
  quantidade de tokens LP a queimar para isso. Defina uma instrução para isso usando um
  discriminador de instrução com valor `2`.
</Requirement>

  <Requirement title="Desafio 4: Troca no Amm">
    Seu programa deve permitir que um usuário faça uma troca no pool de liquidez de um Amm. Defina uma instrução para isso usando um discriminador de instrução com valor `3`.
  </Requirement>
</RequirementList>
