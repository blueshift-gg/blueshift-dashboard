<ChallengeTitle>sBPF Assembly Timeout</ChallengeTitle>

Agora que você está começando a se sentir confortável escrevendo Assembly, em vez de usar o `sol_get_clock_sysvar`, tente alcançar o mesmo objetivo passando a conta `Clock`.

Crie um programa que tenha apenas uma instrução. Ela deve:

- Receber a conta `Clock` (de tamanho 40).
- Receber um u64 (8 bytes) de slot nos dados da instrução.
- Usar os primeiros 8 bytes da conta `Clock` para obter o slot atual.
- Verificar se o slot atual é maior que o slot passado na instrução. Se for, retornar o código de erro 1.

> Para obter o offset correto dos dados da instrução, você pode usar nossa [ferramenta](https://sbpf.xyz). Apenas lembre-se de adicionar uma conta e definir seu comprimento de dados como 40!

Comece instalando o pacote sBPF como explicado na [seção de ferramentas](/pt-BR/courses/introduction-to-assembly/tooling) do curso de Introdução ao Assembly e compile seu programa usando o seguinte comando no seu terminal:

```
sbpf build
```

Isso gerará um arquivo `.so` na sua pasta `target/deploy`.

Agora clique no botão `take challenge` e solte o arquivo lá!

<RequirementList>
  <Requirement title="Desafio 1: Testando o Timeout">
    Seu programa deve ter sucesso quando um slot maior que o atual for passado.
  </Requirement>

  <Requirement title="Desafio 2: Testando a Falha de um Timeout">
    Seu programa deve falhar quando um slot menor que o atual for passado.
  </Requirement>
</RequirementList>
