# SPL 토큰 발행하기

![SPL 토큰 발행 챌린지](/graphics/challenge-banners/typescript-mint-an-spl-token.png)

SPL 토큰 프로그램, 특히 TypeScript를 사용한 토큰 발행은 Solana 개발자로서의 여정에서 첫 번째 시작점이 되어야 합니다.

SPL 토큰 프로그램이 처음이라면, 먼저 [이 강좌](/en/courses/spl-token-with-web3js)를 따라해 보세요!

이 챌린지에서는 네 가지 간단한 명령어를 구현할 것입니다:

- **민트 생성**: 원시 명령어 또는 SDK가 제공하는 추상화된 명령어를 사용하여 `Mint Account`를 생성합니다.
- **민트 초기화**: 원시 명령어 또는 SDK가 제공하는 추상화된 명령어를 사용하여 생성된 `Mint Account`를 초기화합니다. *민트는 6자리 소수점을 가져야 하며, 민트 권한은 코드를 실행하는 지갑으로 설정되고, 동결 권한은 없어야 합니다*.
- **연결된 토큰 계정 생성**: 원시 명령어 또는 SDK가 제공하는 추상화된 명령어를 사용하여 `Associated Token Account`를 생성하고 초기화합니다.
- **2,100만 토큰 발행**: 새로 생성된 토큰 2,100만 개(21,000,000)를 새로 생성된 `Associated Token Account`로 발행합니다.

**참고**: TypeScript로 SPL-Token 프로그램을 사용하는 방법에 익숙하지 않다면, [Web3.js로 SPL 토큰 다루기](/en/courses/spl-token-with-web3js)를 먼저 읽고 이 챌린지에서 필요한 SDK에 익숙해지는 것이 좋습니다.
