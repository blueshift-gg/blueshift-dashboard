# Mintar um SPL Token

![Desafio Mintar um SPL Token](/graphics/challenge-banners/typescript-mint-an-spl-token.png)

O programa SPL token, e especificamente mintar alguns tokens usando TypeScript, deve ser o primeiro ponto de partida na sua jornada como desenvolvedor Solana.

Se você é novo no programa SPL Token, siga [este curso](/pt-BR/courses/spl-token-with-web3js) antes!

Neste desafio, vamos implementar quatro instruções simples:

- **Criar uma Mint**: Criar uma `Mint Account` usando a instrução raw ou a instrução abstraída que o SDK possui.
- **Inicializar a Mint**: Inicializar a `Mint Account` criada usando a instrução raw ou a instrução abstraída que o SDK possui. *A mint deve ter 6 decimais, com a autoridade de mint definida para a wallet que está executando o código, e sem autoridade de freeze*.
- **Criar uma Associated Token Account**: Criar e inicializar uma `Associated Token Account` usando a instrução raw ou a instrução abstraída que o SDK possui.
- **Mintar 21 milhões de Tokens**: Mintar 21 milhões (21.000.000) dos tokens recém-criados para a `Associated Token Account` recém-criada.

**Nota**: Se você não está familiarizado com como usar o programa SPL-Token com TypeScript, deve começar lendo o [SPL Token com Web3.js](/pt-BR/courses/spl-token-with-web3js) para se familiarizar com os SDKs que vamos precisar neste desafio.
