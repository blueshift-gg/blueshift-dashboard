<ArticleSection name="Open Position" id="open-position" level="h2" />

Opening a position creates a new liquidity slot in a price range. The position is represented by an NFT - whoever holds the NFT owns the position and can modify it or collect fees.

<ArticleSection name="Accounts" id="position-accounts" level="h3" />

```rust
#[derive(Accounts)]
pub struct OpenPosition<'info> {
    #[account(mut)]
    pub pool: Account<'info, Pool>,

    #[account(
        init,
        payer = payer,
        space = Position::LEN,
        seeds = [b"position", position_mint.key().as_ref()],
        bump
    )]
    pub position: Account<'info, Position>,

    #[account(
        init,
        payer = payer,
        mint::decimals = 0,
        mint::authority = pool,
    )]
    pub position_mint: Account<'info, Mint>,

    #[account(
        init,
        payer = payer,
        associated_token::mint = position_mint,
        associated_token::authority = owner,
    )]
    pub position_token_account: Account<'info, TokenAccount>,

    #[account(
        mut,
        constraint = tick_array_lower.load()?.pool == pool.key() @ ClammError::InvalidTick
    )]
    pub tick_array_lower: AccountLoader<'info, TickArray>,

    #[account(
        mut,
        constraint = tick_array_upper.load()?.pool == pool.key() @ ClammError::InvalidTick
    )]
    pub tick_array_upper: AccountLoader<'info, TickArray>,

    #[account(
        mut,
        constraint = token_vault_x.mint == pool.token_mint_x,
        constraint = token_vault_x.owner == pool.key()
    )]
    pub token_vault_x: Account<'info, TokenAccount>,

    #[account(
        mut,
        constraint = token_vault_y.mint == pool.token_mint_y,
        constraint = token_vault_y.owner == pool.key()
    )]
    pub token_vault_y: Account<'info, TokenAccount>,

    #[account(mut, constraint = user_token_x.mint == pool.token_mint_x)]
    pub user_token_x: Account<'info, TokenAccount>,

    #[account(mut, constraint = user_token_y.mint == pool.token_mint_y)]
    pub user_token_y: Account<'info, TokenAccount>,

    /// CHECK: The owner of the position NFT (can be any account)
    pub owner: UncheckedAccount<'info>,

    #[account(mut)]
    pub payer: Signer<'info>,

    pub token_program: Program<'info, Token>,
    pub associated_token_program: Program<'info, AssociatedToken>,
    pub system_program: Program<'info, System>,
}
```

Several things to note:

1. **Position is derived from its NFT mint**: `seeds = [b"position", position_mint.key()]`. The NFT mint is generated randomly, making the position PDA unique.

2. **NFT mint has 0 decimals**: Position NFTs are non-fungible - you either have it (1) or you don't (0).

3. **Pool is the mint authority**: The pool PDA controls minting, ensuring exactly one NFT is minted per position.

4. **Two TickArrays**: The lower and upper bounds might be in different arrays. We need both.

5. **Owner vs Payer**: The `owner` receives the NFT, while `payer` pays rent. They can be different accounts.

<ArticleSection name="Validation" id="position-validation" level="h3" />

```rust
impl<'info> OpenPosition<'info> {
    pub fn validate(&self, tick_lower_index: i32, tick_upper_index: i32) -> Result<()> {
        require!(tick_lower_index < tick_upper_index, ClammError::InvalidTickRange);

        check_tick(tick_lower_index, self.pool.tick_spacing)?;
        check_tick(tick_upper_index, self.pool.tick_spacing)
    }
}
```

Both tick bounds must be divisible by tick_spacing and within the global min/max:

```rust
pub fn check_tick(tick: i32, tick_spacing: u16) -> Result<()> {
    require!(tick >= MIN_TICK && tick <= MAX_TICK, ClammError::InvalidTick);
    require!(tick % (tick_spacing as i32) == 0, ClammError::InvalidTick);
    Ok(())
}
```

<ArticleSection name="Updating Ticks" id="updating-ticks" level="h3" />

When a position is created, we update the boundary ticks to reflect the new liquidity:

```rust
impl<'info> OpenPosition<'info> {
    pub fn update_tick(
        &self,
        tick_array: &AccountLoader<'info, TickArray>,
        tick_index: i32,
        liquidity: u128,
        is_upper: bool,
    ) -> Result<()> {
        let mut tick_array = tick_array.load_mut()?;
        let tick = tick_array
            .get_tick_mut(tick_index, self.pool.tick_spacing)
            .ok_or(ClammError::TickNotInArray)?;

        if !tick.is_initialized() {
            tick.initialize(
                tick_index,
                self.pool.tick_current_index,
                self.pool.fee_growth_global_x,
                self.pool.fee_growth_global_y,
            );
        }

        tick.update(liquidity as i128, is_upper);

        Ok(())
    }
}
```

The tick's `update` method handles the liquidity_net calculation:

```rust
impl Tick {
    pub fn update(&mut self, liquidity_delta: i128, is_upper_tick: bool) {
        self.liquidity_gross = if liquidity_delta >= 0 {
            self.liquidity_gross + liquidity_delta as u128
        } else {
            self.liquidity_gross - (-liquidity_delta) as u128
        };

        let current_net = self.get_liquidity_net();
        let new_net = if is_upper_tick {
            current_net - liquidity_delta  // Subtract at upper bound
        } else {
            current_net + liquidity_delta  // Add at lower bound
        };
        self.set_liquidity_net(new_net);

        if self.liquidity_gross == 0 {
            self.initialized = 0;
            self.set_liquidity_net(0);
        }
    }
}
```

The asymmetry is important: at the lower tick, price crossing upward activates the position (+liquidity). At the upper tick, price crossing upward deactivates it (-liquidity).

<ArticleSection name="Fee Growth Checkpoint" id="fee-checkpoint" level="h3" />

We need to checkpoint the current fee growth inside the position's range:

```rust
impl<'info> OpenPosition<'info> {
    pub fn get_fee_growth_inside(
        &self,
        tick_lower_index: i32,
        tick_upper_index: i32,
    ) -> Result<(u128, u128)> {
        let tick_array_lower = self.tick_array_lower.load()?;
        let tick_array_upper = self.tick_array_upper.load()?;

        let tick_lower = tick_array_lower
            .get_tick(tick_lower_index, self.pool.tick_spacing)
            .ok_or(ClammError::TickNotInArray)?;
        let tick_upper = tick_array_upper
            .get_tick(tick_upper_index, self.pool.tick_spacing)
            .ok_or(ClammError::TickNotInArray)?;

        Ok(get_fee_growth_inside(
            tick_lower,
            tick_upper,
            tick_lower_index,
            tick_upper_index,
            self.pool.tick_current_index,
            self.pool.fee_growth_global_x,
            self.pool.fee_growth_global_y,
        ))
    }
}
```

This uses the formula we saw in the state section - computing fees inside from global minus below minus above.

<ArticleSection name="Minting the Position NFT" id="mint-nft" level="h3" />

The pool PDA mints exactly one NFT and then renounces mint authority:

```rust
impl<'info> OpenPosition<'info> {
    pub fn mint_position_nft(&self) -> Result<()> {
        let pool = &self.pool;
        let seeds = &[
            b"pool".as_ref(),
            pool.token_mint_x.as_ref(),
            pool.token_mint_y.as_ref(),
            &[pool.bump],
        ];
        let signer_seeds = &[&seeds[..]];

        // Mint 1 NFT to owner
        token::mint_to(
            CpiContext::new_with_signer(
                self.token_program.to_account_info(),
                MintTo {
                    mint: self.position_mint.to_account_info(),
                    to: self.position_token_account.to_account_info(),
                    authority: self.pool.to_account_info(),
                },
                signer_seeds,
            ),
            1,
        )?;

        // Remove mint authority - no more can ever be minted
        token::set_authority(
            CpiContext::new_with_signer(
                self.token_program.to_account_info(), 
                SetAuthority {
                    current_authority: self.pool.to_account_info(),
                    account_or_mint: self.position_mint.to_account_info()
                }, 
                signer_seeds
            ), 
            token::spl_token::instruction::AuthorityType::MintTokens, 
            None  // No new authority
        )
    }
}
```

Setting the mint authority to `None` is crucial - it makes the NFT truly non-fungible. No one can ever mint another token of this mint.

<ArticleSection name="Token Deposits" id="token-deposits" level="h3" />

The user deposits tokens based on liquidity and price range:

```rust
impl<'info> OpenPosition<'info> {
    pub fn deposit_tokens(&self, amount_x: u64, amount_y: u64) -> Result<()> {
        if amount_x > 0 {
            token::transfer(
                CpiContext::new(
                    self.token_program.to_account_info(),
                    Transfer {
                        from: self.user_token_x.to_account_info(),
                        to: self.token_vault_x.to_account_info(),
                        authority: self.payer.to_account_info(),
                    },
                ),
                amount_x,
            )?;
        }

        if amount_y > 0 {
            token::transfer(
                CpiContext::new(
                    self.token_program.to_account_info(),
                    Transfer {
                        from: self.user_token_y.to_account_info(),
                        to: self.token_vault_y.to_account_info(),
                        authority: self.payer.to_account_info(),
                    },
                ),
                amount_y,
            )?;
        }

        Ok(())
    }
}
```

<ArticleSection name="The Handler" id="position-handler" level="h3" />

Tying it all together:

```rust
pub fn open_position_handler(
    ctx: Context<OpenPosition>,
    tick_lower_index: i32,
    tick_upper_index: i32,
    liquidity: u128,
) -> Result<()> {
    ctx.accounts.validate(tick_lower_index, tick_upper_index)?;

    // Calculate token amounts needed
    let sqrt_price_lower = sqrt_price_from_tick_index(tick_lower_index)?;
    let sqrt_price_upper = sqrt_price_from_tick_index(tick_upper_index)?;
    let (amount_x, amount_y) = get_amounts_for_liquidity(
        ctx.accounts.pool.sqrt_price,
        sqrt_price_lower,
        sqrt_price_upper,
        liquidity,
        true,  // Round up for deposits
    )?;

    // Update boundary ticks
    ctx.accounts.update_tick(&ctx.accounts.tick_array_lower, tick_lower_index, liquidity, false)?;
    ctx.accounts.update_tick(&ctx.accounts.tick_array_upper, tick_upper_index, liquidity, true)?;

    // Checkpoint fee growth
    let (fee_growth_inside_x, fee_growth_inside_y) = 
        ctx.accounts.get_fee_growth_inside(tick_lower_index, tick_upper_index)?;

    // Update pool liquidity if position is in range
    let pool = &mut ctx.accounts.pool;
    if pool.is_price_in_range(tick_lower_index, tick_upper_index) {
        pool.liquidity = pool.liquidity
            .checked_add(liquidity)
            .ok_or(ClammError::LiquidityOverflow)?;
    }

    // Initialize position state
    ctx.accounts.position.set_inner(Position {
        pool: ctx.accounts.pool.key(),
        position_mint: ctx.accounts.position_mint.key(),
        tick_lower_index,
        tick_upper_index,
        liquidity,
        fee_growth_inside_last_x: fee_growth_inside_x,
        fee_growth_inside_last_y: fee_growth_inside_y,
        tokens_owed_x: 0,
        tokens_owed_y: 0,
    });

    // Mint position NFT
    ctx.accounts.mint_position_nft()?;

    // Deposit tokens
    ctx.accounts.deposit_tokens(amount_x, amount_y)?;

    Ok(())
}
```

<ArticleSection name="Close Position" id="close-position" level="h2" />

Closing a position burns the NFT and reclaims the position account rent. It can only be done when liquidity is 0 and all fees are collected.

<ArticleSection name="Accounts" id="close-accounts" level="h3" />

```rust
#[derive(Accounts)]
pub struct ClosePosition<'info> {
    #[account(
        mut,
        close = receiver,
        seeds = [b"position", position_mint.key().as_ref()],
        bump
    )]
    pub position: Account<'info, Position>,

    #[account(
        mut,
        constraint = position_mint.key() == position.position_mint
    )]
    pub position_mint: Account<'info, Mint>,

    #[account(
        mut,
        constraint = position_token_account.mint == position.position_mint,
        constraint = position_token_account.amount == 1,
        constraint = position_token_account.owner == owner.key()
    )]
    pub position_token_account: Account<'info, TokenAccount>,

    pub owner: Signer<'info>,

    /// CHECK: Receives the rent from closed accounts
    #[account(mut)]
    pub receiver: UncheckedAccount<'info>,

    pub token_program: Program<'info, Token>,
}
```

The `close = receiver` attribute tells Anchor to close the account and send rent to `receiver`.

<ArticleSection name="Logic" id="close-logic" level="h3" />

```rust
impl<'info> ClosePosition<'info> {
    pub fn validate(&self) -> Result<()> {
        require!(self.position.liquidity == 0, ClammError::PositionHasLiquidity);
        require!(
            self.position.tokens_owed_x == 0 && self.position.tokens_owed_y == 0,
            ClammError::PositionHasUncollectedFees
        );
        Ok(())
    }

    pub fn burn_position_nft(&self) -> Result<()> {
        token::burn(
            CpiContext::new(
                self.token_program.to_account_info(),
                Burn {
                    mint: self.position_mint.to_account_info(),
                    from: self.position_token_account.to_account_info(),
                    authority: self.owner.to_account_info(),
                },
            ),
            1,
        )
    }

    pub fn close_token_account(&self) -> Result<()> {
        token::close_account(CpiContext::new(
            self.token_program.to_account_info(),
            CloseAccount {
                account: self.position_token_account.to_account_info(),
                destination: self.receiver.to_account_info(),
                authority: self.owner.to_account_info(),
            },
        ))
    }
}

pub fn close_position_handler(ctx: Context<ClosePosition>) -> Result<()> {
    ctx.accounts.validate()?;
    ctx.accounts.burn_position_nft()?;
    ctx.accounts.close_token_account()?;
    Ok(())
}
```

Notice that ownership is verified through the NFT constraints - whoever holds the NFT (amount == 1, owner == signer) can close the position.

The position account itself is closed by Anchor's `close` attribute. We explicitly burn the NFT and close its token account to return all rent.
