<ChallengeTitle>Anchor CLAMM</ChallengeTitle>

It's now time to put what you've learned to the test. Build a Concentrated Liquidity AMM program using the Anchor framework that satisfies the following requirements:

<RequirementList>
  <Requirement title="Challenge 1: Initialize Pool">
    Create a pool for two tokens with an initial sqrt_price computed from token amounts. The pool should store fee_rate, tick_spacing, and global fee accumulators. Pool PDA should be derived from both token mints (sorted lexicographically).
  </Requirement>

  <Requirement title="Challenge 2: Initialize Tick Array">
    Allow lazy creation of TickArrays for different price ranges. Each array holds 88 ticks and must have a start_tick_index aligned to TICK_ARRAY_SIZE * tick_spacing. Use zero_copy for efficient storage.
  </Requirement>

  <Requirement title="Challenge 3: Open Position">
    Create a liquidity position in a tick range [lower, upper). Mint an NFT to represent ownership. Update boundary ticks with liquidity_net and liquidity_gross. Calculate required token amounts based on current price and range. Checkpoint fee_growth_inside for the position.
  </Requirement>

  <Requirement title="Challenge 4: Close Position">
    Allow the NFT holder to close an empty position (liquidity = 0, no uncollected fees). Burn the position NFT and reclaim account rent.
  </Requirement>

  <Requirement title="Challenge 5: Add Liquidity">
    Increase liquidity in an existing position. Update fees first, then calculate token amounts (round up), update ticks and pool liquidity, and transfer tokens from user to vault.
  </Requirement>

  <Requirement title="Challenge 6: Remove Liquidity">
    Decrease liquidity in an existing position. Update fees first, then calculate token amounts (round down), update ticks and pool liquidity, and transfer tokens from vault to user using PDA signing.
  </Requirement>

  <Requirement title="Challenge 7: Collect Fees">
    Allow the NFT holder to collect accumulated fees. Compute fee_growth_inside from tick boundaries, update position's tokens_owed, and transfer fees from vault to user.
  </Requirement>

  <Requirement title="Challenge 8: Swap">
    Execute swaps across tick boundaries. Loop through swap steps, crossing initialized ticks and updating liquidity. Accumulate fees to fee_growth_global. Include slippage protection with min_amount_out.
  </Requirement>
</RequirementList>

Build your program:

```bash
anchor build
```

This generates a `.so` file in your `target/deploy` folder.

Click the **Take Challenge** button and upload the file!
