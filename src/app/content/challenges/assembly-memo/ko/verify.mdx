<ChallengeTitle>sBPF 어셈블리 메모</ChallengeTitle>

하나의 명령어만 가진 프로그램을 만드세요. 다음 조건을 충족해야 합니다:
- 명령어 데이터에 계정이 포함되어 있으면 실패해야 합니다 (`r0`를 계정 수로 설정하여 수행할 수 있습니다)
- `r2`를 명령어 데이터의 길이로 설정하고, `r1`를 명령어 데이터의 오프셋으로 설정합니다
- `sol_log_` 시스템 콜을 호출합니다.

어셈블리 입문 과정의 [도구 섹션](/en/courses/introduction-to-assembly/tooling)에서 설명한 대로 sBPF 패키지를 설치하고 터미널에서 다음 명령어를 사용하여 프로그램을 빌드하세요:

```
sbpf build
```

이렇게 하면 `target/deploy` 폴더에 `.so` 파일이 생성됩니다.

이제 `take challenge` 버튼을 클릭하고 파일을 드롭하세요!
