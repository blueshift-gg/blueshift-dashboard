## Refund 명령 (Refund Instruction)

이제 `refund.rs`에 위치할 `refund` 명령으로 넘어가겠습니다. 이 명령은 다음과 같은 작업을 수행합니다:

- 에스크로 PDA를 닫고, 해당 계정에 보관되어 있던 렌트비(lamports)를 생성자(Maker)에게 돌려줍니다.
- 금고(Vault)에 있는 토큰 A 잔액 전체를 생성자에게 다시 전송한 뒤, 금고 계정을 폐쇄합니다.

### 계정 (Accounts)

이 컨텍스트에서 필요한 계정들은 다음과 같습니다:

- **`maker`**: 거래 조건을 결정했던 사용자입니다.
- **`escrow`**: 거래 조건이 저장되어 있는 계정입니다.
- **`mint_a`**: 생성자가 예치했던 토큰의 민트 주소입니다.
- **`vault`**: 토큰이 예치되어 있는 에스크로 소유의 토큰 계정입니다.
- **`maker_ata_a`**: 금고로부터 토큰을 돌려받을 생성자의 토큰 계정입니다.
- **`associated_token_program`**: 연관 토큰 계정 생성에 사용되는 프로그램입니다.
- **`token_program`**: 전송(Transfer) CPI를 위한 토큰 프로그램입니다.
- **`system_program`**: 에스크로 계정 처리를 위한 시스템 프로그램입니다.

**이번에는 직접 `Context` 구조체를 작성해 보세요!** 계정의 순서가 틀리면 테스트가 실패할 수 있으니 주의해서 올바른 순서로 정의해 보시기 바랍니다.

### 로직 (Logic)

로직은 `take` 명령과 유사하지만, 이번에는 비어있는 금고를 닫기 전에 토큰을 `vault`에서 `maker_ata_a`로 옮기기만 하면 됩니다.

직접 스스로 학습하며 구현해 볼 수 있도록 이번에는 정답 코드를 제공하지 않습니다.

이 명령이 성공적으로 실행되면 제안은 무효화되고, 금고는 사라지며, 생성자는 자신의 토큰 A와 렌트비를 지갑으로 다시 돌려받게 된다는 점을 기억하세요.

## 진입점 (Entrypoint)

각 모듈에 모든 함수를 작성했다면, 이제 `lib.rs`를 우리가 만든 함수들로 채워 넣을 차례입니다. 다음과 같은 모습이 될 것입니다:

```rust
#[program]
pub mod blueshift_anchor_escrow {
    use super::*;

    pub fn make(ctx: Context<Make>, seed: u64, receive: u64, amount: u64) -> Result<()> {
        instructions::make::handler(ctx, seed, receive, amount)
    }

    pub fn take(ctx: Context<Take>) -> Result<()> {
        instructions::take::handler(ctx)
    }

    pub fn refund(ctx: Context<Refund>) -> Result<()> {
        instructions::refund::handler(ctx)
    }
}
```
