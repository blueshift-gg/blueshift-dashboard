<ChallengeTitle>Anchor 에스크로</ChallengeTitle>

이제 배운 내용을 테스트할 시간입니다. 레슨에서 배운 내용을 활용하여 다음 요구사항을 충족하는 Anchor 프레임워크 기반 에스크로 프로그램을 구축하세요:

> 상태 계정은 `1` 값을 가진 계정 식별자를 사용하여 정의되어야 합니다.

<RequirementList>
  <Requirement title="챌린지 1: 에스크로 제안 만들기">
    프로그램은 제안자가 에스크로 제안을 만들 수 있도록 허용해야 합니다. `0` 값을 가진 명령어 식별자를 사용하여 이를 수행하는 명령어를 정의하세요.
  </Requirement>

  <Requirement title="챌린지 2: 에스크로 제안 수락하기">
    프로그램은 수락자가 에스크로 제안을 수락할 수 있도록 허용해야 합니다. `1` 값을 가진 명령어 식별자를 사용하여 이를 수행하는 명령어를 정의하세요.
  </Requirement>

  <Requirement title="챌린지 3: 에스크로 제안 취소하기">
    프로그램은 제안자가 에스크로 제안을 취소하고 에스크로된 자금을 환불할 수 있도록 허용해야 합니다. 명령어가 `2` 값을 가진 명령어 식별자로 정의되었는지 확인하세요.
  </Requirement>
</RequirementList>
