<ChallengeTitle>Pinocchio Escrow</ChallengeTitle>

Agora é hora de colocar o que você aprendeu em prática. Usando o que aprendeu na lição, construa um programa de escrow usando o framework Pinocchio que satisfaça os seguintes requisitos:

<RequirementList>
  <Requirement title="Desafio 1: Fazendo uma oferta de escrow">
    Seu programa deve permitir que um maker faça uma oferta de escrow. Defina uma instrução para isso usando um discriminador de instrução com valor `0`.
  </Requirement>

  <Requirement title="Desafio 2: Aceitando uma oferta de escrow">
    Seu programa deve permitir que um taker aceite uma oferta de escrow. Defina uma instrução para isso usando um discriminador de instrução com valor `1`.
  </Requirement>

  <Requirement title="Desafio 3: Cancelando uma oferta de escrow">
    Seu programa deve permitir que o maker cancele uma oferta de escrow e reembolse os fundos em garantia. Certifique-se de que sua instrução seja definida com um discriminador de instrução com valor `2`.
  </Requirement>
</RequirementList>
