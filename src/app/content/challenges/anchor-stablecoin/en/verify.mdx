To verify your Anchor Stablecoin implementation, submit your program ID below.

The verification server will run comprehensive tests covering:

### Core Instructions
- `initialize`: Config PDA created with Pyth feed, ratios stored correctly
- `open_position`: Collateral deposited, stablecoins minted, position tracked
- `repay_position`: Debt burned, interest paid in collateral, collateral returned
- `liquidate`: Health check enforced, liquidator bonus calculated, position cleared

### Pyth Integration
- Price fetched using `get_price_no_older_than`
- Staleness check enforced (120 second maximum age)
- Feed ID validated against config
- Price exponent handled correctly in conversions

### Collateralization
- Collateral requirement enforced at position open
- Interest accrual calculated correctly over time
- Health factor computed with interest-adjusted collateral
- Liquidation threshold properly enforced

### Safety Checks
- Flash loan protection via minimum position duration
- Slippage protection on collateral amounts
- Zero/negative price rejection
- Proper decimal handling across different token decimals

### Edge Cases
- Partial repayment updates position correctly
- Full repayment closes position and refunds rent
- Post-liquidation positions can withdraw remaining collateral
- Interest calculated correctly at various time intervals

Good luck!
