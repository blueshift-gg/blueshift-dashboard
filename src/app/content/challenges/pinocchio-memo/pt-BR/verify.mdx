# Programa Memo com Pinocchio

Bem-vindo ao seu primeiro desafio usando Pinocchio! Seu objetivo é criar um programa de memo simples que registra uma mensagem na blockchain. Esta é uma ótima introdução ao funcionamento das instruções no Pinocchio.

O programa tem apenas uma instrução e nenhuma conta. Ele usa diretamente o `instruction_data` como fonte da string, e então simplesmente registra essa string usando a syscall `sol_log`.

Seu programa também deve ter um program Id de `22222222222222222222222222222222222222222222` para passar no desafio.
