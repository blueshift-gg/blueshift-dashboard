# Programa Memo com Anchor

Bem-vindo ao seu primeiro desafio usando o framework Anchor na Solana! Seu objetivo é **criar um programa simples de memo que registre uma mensagem** na blockchain. Esta é uma ótima introdução ao funcionamento das instruções no Anchor.

O programa tem apenas uma instrução e recebe:

- Uma entrada `String`
- Nenhuma conta

Em seguida, simplesmente registra essa string usando a macro `msg!()` do Anchor.

Seu programa também deve ter um Program ID de `22222222222222222222222222222222222222222222` para passar no desafio.
