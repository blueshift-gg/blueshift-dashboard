<ChallengeTitle>StableSwap AMM</ChallengeTitle>

It's time to build a StableSwap AMM - the backbone of stablecoin trading. Using what you've learned from the lesson, implement a multi-token StableSwap pool that satisfies the following requirements:

<RequirementList>
  <Requirement title="Challenge 1: Initialize Pool">
    Your program should allow anyone to initialize a new StableSwap pool with 2-6 tokens. The instruction should accept an amplification coefficient and fee (in basis points), create the pool account with a PDA derived from the LP mint, and store all token mints. Token vaults should be Associated Token Accounts owned by the pool PDA.
  </Requirement>

  <Requirement title="Challenge 2: Add Liquidity">
    Your program should allow users to deposit tokens and receive LP tokens in return. For the first deposit, LP tokens minted should equal the D invariant minus MINIMUM_LIQUIDITY (to prevent inflation attacks). For subsequent deposits, calculate LP tokens proportionally based on the change in D. Support imbalanced deposits where users can provide different amounts of each token.
  </Requirement>

  <Requirement title="Challenge 3: Remove Liquidity">
    Your program should allow LP token holders to burn their tokens and withdraw a proportional share of all pool tokens. The withdrawal amounts should be calculated as: `amount_i = reserve_i * lp_burned / total_lp_supply`. Include slippage protection with minimum amount parameters.
  </Requirement>

  <Requirement title="Challenge 4: Swap">
    Your program should allow users to swap one token for another using the StableSwap curve. Implement Newton's method to compute the new reserve after a swap. Apply the fee (in basis points) to the output amount. Include slippage protection with a minimum output parameter.
  </Requirement>
</RequirementList>
