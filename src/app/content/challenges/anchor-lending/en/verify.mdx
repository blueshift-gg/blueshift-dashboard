To verify your Anchor Lending implementation, submit your program ID below.

The verification server will run comprehensive tests covering:

### Core Instructions
- `init_market`: Market PDA created with correct bump
- `init_reserve`: Reserve configured with risk parameters
- `init_obligation`: Obligation linked to market and owner
- `deposit`: Tokens transferred, shares minted, state updated
- `withdraw`: Shares burned, tokens returned, state updated
- `borrow`: LTV enforced, debt tracked, tokens transferred
- `repay`: Debt reduced, tokens returned to vault
- `liquidate`: Health check, close factor, bonus calculation

### Interest & Pricing
- Interest accrual updates cumulative rate correctly
- Share exchange rate grows with interest
- Oracle prices cached on refresh
- USD value calculations handle decimals

### Safety Checks
- Staleness validation on all price-dependent operations
- Same-slot refresh requirement for liquidations
- Vault balance verification after transfers
- Proper error codes for invalid states

### Edge Cases
- Zero amount operations rejected
- Insufficient collateral prevents borrows
- Healthy positions can't be liquidated
- Close factor limits liquidation size

Good luck!
