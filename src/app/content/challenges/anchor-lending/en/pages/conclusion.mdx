<ArticleSection name="Security Considerations" id="security" level="h2" />

Before deploying any lending protocol, ensure you've addressed:

### Oracle Security
- Use multiple price sources with fallbacks
- Implement staleness checks on all price reads
- Consider confidence intervals for conservative pricing
- Set bounds on price changes between updates

### Economic Security
- Stress test liquidation cascades
- Model bad debt scenarios
- Size insurance fund appropriately
- Consider circuit breakers for extreme volatility

### Code Security
- Audit by multiple independent parties
- Formal verification of critical math
- Extensive fuzzing of edge cases
- Bug bounty program

Ideas to extend this protocol:

### Flash Loans
Allow uncollateralized borrows that must be repaid in the same transaction:

```rust
pub fn flash_loan(ctx: Context<FlashLoan>, amount: u64) -> Result<()> {
    let balance_before = ctx.accounts.vault.amount;
    
    // Transfer to borrower
    transfer_out(amount)?;
    
    // Borrower does their thing via CPI...
    
    // Verify repayment with fee
    ctx.accounts.vault.reload()?;
    let fee = amount * FLASH_FEE_BPS / BPS_SCALE;
    require!(
        ctx.accounts.vault.amount >= balance_before + fee,
        LendingError::FlashLoanNotRepaid
    );
    
    Ok(())
}
```

### E-Mode
Higher LTV for correlated assets:

```rust
pub struct EMode {
    pub assets: Vec<Pubkey>,
    pub ltv_bps: u16,           // e.g., 93% for stETH/ETH
    pub liq_threshold_bps: u16, // e.g., 95%
}
```

### Isolated Markets
Per-asset risk isolation:

```rust
pub struct IsolatedConfig {
    pub debt_ceiling: u64,
    pub current_debt: u64,
    pub allowed_borrows: Vec<Pubkey>,
}
```

### Stable Borrow Rates
Lock in a rate at borrow time:

```rust
pub struct StableBorrow {
    pub principal: u64,
    pub stable_rate: u64,
    pub last_update: i64,
}
```

<ArticleSection name="Testing" id="testing" level="h2" />

Key scenarios to test:

1. **Happy path**: Deposit → Borrow → Repay → Withdraw
2. **Liquidation flow**: Price drop → Refresh → Liquidate
3. **Interest accrual**: Verify rates and compounding
4. **Multi-position**: Multiple collaterals and borrows
5. **Edge cases**: Zero amounts, max values, empty positions
6. **Attack vectors**: Stale data, reentrancy, oracle manipulation
